# Microsoft Office is configured to prevent activation of Object Linking and Embedding packages.

| Property | Value |

## Summary

Configure **Activation of OLE packages** via **Microsoft Office** and deploy **OfficeMacroHardeningPreventActivationOfOle.ps1** using **InTune 'Scripts' option**.[^1]

[^1]: [Essential Eight user application hardening - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Design Decision

Use **Microsoft Office** to configure **OLE package activation prevention** and deploy **OfficeMacroHardeningPreventActivationOfOle.ps1** via **InTune Scripts option**.

> [!NOTE]
> Deploying **OfficeMacroHardeningPreventActivationOfOle.ps1** also disables OLE package activation in Office.

## Prerequisites

### Dependencies
- Availability of the script **OfficeMacroHardening-PreventActivationofOLE.ps1**.[^1]
- The script is specifically for Office 2016 and later.[^1]

### Permissions/Roles
- Assign the script to a deployment group.[^1]

[^1]: [Essential Eight user application hardening - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Implementation Steps

### Deploy Script using Intune Scripts

1. Add the **OfficeMacroHardeningPreventActivationOfOle.ps1** as a PowerShell script using Intune **Scripts**.[^1]

2. Configure the script with the following options:

| Setting | Value |
| ------- | ----- |
| **Run this script using the logged on credentials** | **Yes** |
| **Enforce script signature check** | **No** |
| **Run script in 64-bit PowerShell Host** | **No** |

3. Assign the script to a deployment group.[^1]

> [!NOTE]
> This PowerShell script is specifically for Office 2016 and later. A script to prevent the activation of OLE for Office 2013 is provided here: **OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1**.[^1]

[^1]: [Essential Eight user application hardening on Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)
