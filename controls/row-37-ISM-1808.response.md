## Summary

Onboard devices to **Microsoft Defender for Endpoint**.[^1]

Use the **Microsoft Defender** security portal report under **Exposure management** > **Vulnerabilities** to view vulnerability findings.[^2]

[^1]: [Essential Eight patch operating systems - Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)
[^2]: [Threat and vulnerability management - Microsoft Service Assurance](https://learn.microsoft.com/en-us/compliance/assurance/assurance-vulnerability-management)

## Design Decision

Use **Microsoft Defender for Endpoint** to onboard devices and access the **Exposure management** > **Vulnerabilities** report in the **Microsoft Defender** security portal.

> [!NOTE]
> Onboarding devices enables centralized visibility of vulnerabilities via the **Exposure management** > **Vulnerabilities** view.

## Prerequisites

- **Licensing:** Microsoft Defender Vulnerability Management (DVM), or Microsoft Defender for Endpoint Plan 2 or E5 license provides core vulnerability management capabilities.[^1]

- **Licensing – Intune configuration:** If Microsoft Intune is used to configure devices, Microsoft Intune Plan 1 licensing at minimum.[^2]

- **Permissions/Roles:** A Defender Vulnerability Management user permission is required to access vulnerability management features.[^4]

- **Dependencies:** Windows desktop devices running Windows 10 or later must be onboarded to Microsoft Defender for Endpoint.[^3]

## Implementation Steps

### Onboard Endpoints to Microsoft Defender for Endpoint

1. Create a new **Settings Catalog** policy with a Windows Configuration Profile of type Template: **Microsoft Defender for Endpoint** for desktop devices running Windows 10 or later. [^1]

2. Configure the following setting:
   - **Telemetry reporting frequency**: Enable

   ```
   | Setting | Value |
   | ------- | ----- |
   | **Telemetry reporting frequency** | Enable |
   ```

   [^1]

3. Assign the policy to a group containing all applicable Windows devices. [^1]

### Review Vulnerabilities in Exposure management Portal

1. After onboarding, use **Defender Vulnerability Management** to perform vulnerability scanning. Production assets are scanned daily with the most recent vulnerability signatures. [^2]

2. Open the Microsoft Defender security portal and navigate to Exposure management > Vulnerabilities to view findings. [^2]

3. Track identified vulnerabilities until remediation and prioritize actions based on CVSS scores and other risk factors. [^2]
