## Summary

Onboard devices to Microsoft Defender for Endpoint. Then use the Microsoft Defender security portal's Exposure management > Vulnerabilities report to monitor vulnerabilities[^1][^5]. Automated vulnerability management and scanning should be employed to rapidly remediate weaknesses and prioritize fixes using risk-based criteria[^1][^2].

[^1]: [Posture and Vulnerability Management](https://learn.microsoft.com/en-us/security/benchmark/azure/mcsb-v2-posture-vulnerability-management#pv-6-rapidly-and-automatically-remediate-vulnerabilities#pv-6-rapidly-and-automatically-remediate-vulnerabilities)
[^2]: [Enable vulnerability scanning](https://learn.microsoft.com/en-us/azure/defender-for-cloud/deploy-vulnerability-assessment-defender-vulnerability-management#enable-vulnerability-scanning-on-a-subscription)
[^5]: [Security Control: Vulnerability Management](https://learn.microsoft.com/en-us/security/benchmark/azure/security-control-vulnerability-management)
