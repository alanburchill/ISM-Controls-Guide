# A vulnerability scanner is used at least weekly to identify missing patches or updates for vulnerabilities in office productivity suites, web browsers and their extensions, email clients, PDF applications, and security products.

## Summary

Onboard devices to Microsoft Defender for Endpoint. Use the Defender exposure management report under Vulnerabilities to identify and prioritize vulnerabilities across office productivity suites, web browsers and their extensions, email clients, PDF software, and security products on a weekly basis, enabling timely remediation and reduced risk.[^1]

## Design Decision

> [!NOTE]
> Devices will be onboarded to **Microsoft Defender for Endpoint**. The **Microsoft Defender** security portal report under Exposure management > Vulnerabilities will be used to monitor vulnerability exposure.

## Prerequisites

- **Permissions/Roles**
  - **Owner** permissions (resource group level) to deploy the vulnerability scanner. [^4]
  - **Security Reader** role to view findings. [^4]

- **Dependencies**
  - **Microsoft Defender for Endpoint** onboarding of devices. [^1]
  - **Intune connection** must be enabled in the Defender portal to use remediation workflow. [^1]
  - **Security agent** installed on assets to enable vulnerability scanning. [^6]
  - Defender for Cloud vulnerability scanning prerequisites:
    - Agent-based vulnerability scanning requires Defender for Servers Plan 1 (P1) or 2 (P2) to be enabled. [^4]
    - Agentless vulnerability scanning is available and turned on by default when Defender for Servers Plan 2 or Defender for Servers CSPM plan is enabled. [^4]

## Implementation Steps

### Onboard devices to Microsoft Defender for Endpoint and view the Vulnerabilities report

1. Onboard devices to Microsoft Defender for Endpoint.[^1]
2. In the Microsoft Defender portal, enable the Intune connection to support remediation workflows:
   - Navigate to **Settings** > **Endpoints** > **General** > **Advanced features**.
   - Locate the Microsoft Intune connection toggle and turn it On.[^1]
3. Open the Vulnerability management navigation menu in the Microsoft Defender portal and access the Vulnerabilities report under Exposure management. Review vulnerabilities identified for onboarded devices.[^1]
4. To remediate, use the remediation workflow:
   - In Vulnerability management, select a security recommendation and choose **Remediation options** to fill out the remediation form.[^1]
   - Submitting a remediation request creates a remediation activity item and a security task in Intune; monitor progress on the Remediation page and in Intune.[^1]
   - The Intune admin selects the security task to view details, then selects **Accept** to update the status in Intune and in Defender for Endpoint.[^1]
   - Remediate according to the guidance provided; remediation guidance may include links that open relevant panes in Intune.[^1]
