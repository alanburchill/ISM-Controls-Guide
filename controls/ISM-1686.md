## Summary

Configure **Credential Guard Configuration** via Intune device configuration profile and deploy **ScriptName.ps1** using Settings Catalog policy.[^1]

[^1]: [Configure Credential Guard](https://learn.microsoft.com/en-us/windows/security/identity-protection/credential-guard/configure)

## Design Decision

Use **Microsoft Intune** to (1) configure **Credential Guard Configuration** and (2) deploy **ScriptName.ps1** via **Settings Catalog policy**.

> [!NOTE]
> Deploying **ScriptName.ps1** via Settings Catalog policy enables Credential Guard across managed devices.

## Prerequisites

* **Dependencies:** Access to **Microsoft Intune** and the ability to create and deploy a **Settings Catalog** policy; assign the policy to a group containing the devices or users to configure.[^1]
* **Dependencies:** Credential Guard configuration is recommended to be configured via **Microsoft Intune** settings catalog policy.[^2]

[^1]: [Configure Credential Guard](https://learn.microsoft.com/en-us/windows/security/identity-protection/credential-guard/configure)
[^2]: [Essential Eight restrict administrative privileges](https://learn.microsoft.com/en-us/compliance/anz/e8-admin)

## Implementation Steps

### Configure Credential Guard using Settings Catalog

1. Create a new **Settings Catalog** policy.[^1]
2. Add the following device configuration settings and values:

| Setting | Value |
| ------- | ----- |
| Turn On Virtualization Based Security (DeviceGuard EnableVirtualizationBasedSecurity) | 1 |
| Credential Guard Configuration - Enabled with UEFI lock (DeviceGuard LsaCfgFlags) | 1 |
| Credential Guard Configuration - Enabled without lock (DeviceGuard LsaCfgFlags) | 2 |

3. Deploy the policy to a group that contains the devices or users you want to configure.[^1]
4. Restart the device after policy application. Enabling Credential Guard enables Virtualization-Based Security and Secure Boot during boot, which requires a restart to take effect.[^2]

### Configure Credential Guard using a Custom Policy CSP

1. Create a custom policy using the **DeviceGuard Policy CSP** with the following settings:

| Setting | Value |
| ------- | ----- |
| Turn On Virtualization Based Security (DeviceGuard EnableVirtualizationBasedSecurity) | 1 |
| Credential Guard Configuration (DeviceGuard LsaCfgFlags) - Enabled with UEFI lock | 1 |
| Credential Guard Configuration (DeviceGuard LsaCfgFlags) - Enabled without lock | 2 |

2. Assign the policy to the appropriate device group.[^1]
3. Restart the device after policy application. Enabling Credential Guard via a CSP policy follows the same reboot requirement as Settings Catalog configuration.[^2]

> [!NOTE]
> Enabling Credential Guard enables Virtualization-based Security (VBS) and Secure Boot protections. A reboot is required for these changes to take effect.[^2]
