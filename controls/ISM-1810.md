## Summary

Configure **Backups synchronization for common point in time restoration** via **Azure Backup** to take application-consistent snapshots and enable synchronised restore points.[^1]

[^1]: [Why Pursue ACSC Essential Eight User Backup Guidelines? - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-backups)

## Design Decision

Use **Azure Backup** to (1) configure **application-consistent snapshots for synchronised restore points** and (2) deploy **BackupDeployment.ps1** via **Azure Automation**.

> [!NOTE]
> The design uses **Azure Backup** to ensure application-consistent snapshots and synchronised restore points.

## Prerequisites

No specific prerequisites identified in source documentation.

## Implementation Steps

### Configure Azure Backup Center for application-consistent snapshots

1. Deploy the **Azure Backup Center** to provide centralized backup management across multiple vaults and regions. [^2]

2. Use **Azure Backup Center** and **Azure Backup Reports** to gain visibility into backup health, job status, and storage trends. [^2]

3. Implement automated alerting for backup failures, restore errors, and retention policy changes using **Azure Monitor** and **Azure Policy** dashboards. Route alerts to the on-call team. [^2]

4. Ensure backups are synchronized to enable restoration to a common point in time, aligning with business continuity requirements. This aligns with guidance that backups of data, applications, and settings are synchronized to enable restoration to a common point in time. [^1]

### Validate restore capabilities and DR readiness

1. Conduct disaster recovery exercises to test restoration of data, applications, and settings from backups to a common point in time. [^1]
