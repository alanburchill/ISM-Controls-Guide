## Summary

Microsoft Office macros are disabled by default for users without a demonstrated business requirement. Not provided in source documentation. Macros from the Internet are blocked by policy, and macros are checked to ensure they're free of malicious code before being digitally signed or placed within trusted locations.[^2][^3]

## Design Decision

> [!NOTE] A group exempt from the macro-disabling policy will be created and populated only with users approved to run macros. Membership is managed and reviewed periodically using an Entra ID Access Package.

## Prerequisites

- **Permissions/Roles:** Create a group for users excluded from the macro policy; only add users approved to run macros to this group. Implement an Entra ID Access Package to periodically review membership.
- **Dependencies:** Entra ID Access Package to support periodic membership reviews.
