# Patches, updates or other vendor mitigations for vulnerabilities in operating systems of workstations, non-internet-facing servers and non-internet-facing network devices are applied within 48 hours of release when vulnerabilities are assessed as critical by vendors or when working exploits exist.

## Summary

Push critical OS patches within 48 hours using **Intune expedited updates** with **Windows Autopatch** for Windows 10 and later devices.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Design Decision

Use **Intune** to configure **Quality updates expediting** and deploy **Windows Autopatch** to push critical OS patches within 48 hours.

> [!NOTE]
> Expedited quality updates via **Intune** and **Windows Autopatch** will deliver patches within 48 hours.

## Prerequisites

### Dependencies
- An Intune-enabled environment to manage Windows Update for Business policies that expedite quality updates for Windows 10 and later. [^1]
- The ability to create and assign the policy to a group containing all applicable Windows devices. [^1]

[^1]: [Essential Eight patch operating systems - Essential Eight](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Implementation Steps

### Configure Expedited Quality Updates with Settings Catalog

1. Create a new **Quality updates for Windows 10 and later** policy under Devices > Windows > Quality updates for Windows 10 and later (Preview).[^1]

2. Provide a name. It is suggested that the policy name aligns to the quality update version being expedited for ease of reference.[^1]

3. Define the quality updates that Windows Update for Business expedites the installation of if the device OS version is less than.[^1]

4. Define the number of days until a restart is enforced.

| Setting | Value |
| ------- | ----- |
| Restart enforcement delay (days) | Not provided in source documentation |

5. Assign the policy to a group containing all applicable Windows devices.[^1]

### Update Rings and Client-Side Settings to Support Expedited Patching

1. Update rings are policies that are assigned to groups of devices. Intune can define update rings that specify how and when service updates are deployed to Windows devices.[^2]

2. To deploy patches to endpoints as quickly as possible, client-side settings should not restrict or delay the installation of patches where it does not interfere with critical operation or cause loss of data due to unexpected reboots.[^2]

3. Assign update rings to groups of devices to mirror business needs and ensure patches are deployed promptly.[^2]

4. Assign the policy to a deployment group to ensure coverage across applicable devices.[^2]

> [!NOTE]
> The steps above align with Windows Update for Business expedited patch deployment methods to reduce deployment time.[^1]
