## Summary

Configure **Windows Autopatch** for all workstations via the **InTune admin portal** and enable it across the fleet.[^1] Deploy patches for third-party applications through the **InTune Enterprise Application Catalogue**, or repackage and redeploy security updates within the required timeline, and configure all devices to **Targe Channel** or **Stable** for the Edge browser.[^1]

[^1]: [Essential Eight patch applications](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app)

## Design Decision

Use **Windows Autopatch** to configure and enable patch management for all workstations via the **InTune admin portal** and to deploy updates. Use **InTune Enterprise Application Catalogue** to deploy new versions of third-party applications, or repackage and redeploy those requiring security updates within the timeline; configure the Edge browser to **Target Channel** or **Stable**.

> [!NOTE]
> The decision enables centralized patching via **Windows Autopatch** and centralized third-party app updates via **InTune Enterprise Application Catalogue**.

## Prerequisites

- **Access to the Intune admin portal** to configure Windows Autopatch for all workstations. [^1]
- **Ability to deploy third-party application patches via Microsoft Intune** within one month of release. [^1]
- **Ability to define and apply update rings using Microsoft Intune** to manage patch deployment timing. [^3]

[^1]: [Essential Eight patch applications](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app)
[^3]: [ASD Blueprint: Windows update and patching](https://blueprint.asd.gov.au/design/endpoints/windows/configuration/windows-update-and-patching/)

## Implementation Steps

### Enable Windows Autopatch for all workstations via the InTune admin portal

1. Configure and enable **Windows Autopatch** for all workstations via the InTune admin portal. [^1]

### Deploy third-party application patches via Intune Enterprise Catalogue

1. Deploy new version of third-party applications via **Intune Enterprise Catalogue** when patches are released. [^1]

2. If a patch is not available in the Enterprise Catalogue, re-packaged and redeploy all applications that require security updates within the timeline. [^1]

### Configure Edge browser to **Targe Channel** or **Stable**

1. Configure all devices to **Targe Channel** or **Stable** for the Edge web browser. [^3]
