# Microsoft Office macros are blocked from making Win32 API calls.

## Summary

Microsoft Office macros are blocked from making Win32 API calls by enabling the ASR rule Block Win32 API calls from Office macros, preventing a common malware technique used by macro-based attacks. This policy is implemented through Intune as part of Attack Surface Reduction configurations.[^1][^2][^3]

[^1]: Essential Eight configure Microsoft Office macro settings (https://learn.microsoft.com/en-us/compliance/anz/e8-macro)

[^3]: Attack Surface Reduction rules reference (https://github.com/MicrosoftDocs/defender-docs/blob/public/defender-endpoint/attack-surface-reduction-rules-reference.md)

## Design Decision

> [!NOTE]
> The **ACSC Windows Hardening Guidelines-Attack Surface Reduction.json policy** will be deployed via **Intune** to enable the ASR rule **Block Win32 API calls from Office macros**.
> This will block Office macros from making Win32 API calls in accordance with ACSC Office Hardening guidance.
