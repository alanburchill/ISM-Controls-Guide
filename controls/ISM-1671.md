# Microsoft Office macros are disabled for users that do not have a demonstrated business requirement.

## Summary

Configure the **Allow macro execution - Trusted Publisher** group to exempt approved users from the default policy that disables Office macros, and deploy the **All Macros Disabled** policy to all Office users while excluding this group. Implement an **Entra ID Access Package** to periodically review membership.[^1]

[^1]: [Essential Eight configure Microsoft Office macro settings](https://learn.microsoft.com/en-us/compliance/anz/e8-macro)

## Design Decision

Use **Microsoft Office macros policy** to (1) configure **All Macros Disabled policy** and (2) deploy **OfficeMacroHardening-PreventActivationofOLE.ps1** via **Intune deployment group**.

> [!NOTE]
> Deploying **OfficeMacroHardening-PreventActivationofOLE.ps1** also disables activation of OLE packages in Office applications.

## Prerequisites

### Licensing
- If Intune is used to configure devices (e.g., deploying scripts, Settings Catalog policies, or configuration profiles), target devices require **Microsoft Intune Plan 1** licensing at minimum. This licensing is typically included in **Microsoft 365 E3** or higher subscriptions.[^1]

### Permissions/Roles
- Create a group named **Allow macro execution - Trusted Publisher** that contains users who are approved to run Office macros signed by a Publisher.[^2]

## Implementation Steps

### Excluded Group Setup and Macro Policy Exemption

1. Create a new group named **Allow macro execution - Trusted Publisher** that contains users approved to run Office macros if they're signed by a Publisher. This group is excluded from the standard policy and is allowed to execute macros that are signed by a Trusted Publisher.[^1]

2. Create or import the policy **All Macros Disabled** and deploy it to All Office Users. Exclude the **Allow macro execution - Trusted Publisher** group from this policy to enable macro execution for approved users.[^1]

3. Validate that the policy blocks macros for all non-exempt users and allows macros for members of the exempt group when signed by a Trusted Publisher.[^1]

4. Ensure that only users approved to run macros are added to the **Allow macro execution - Trusted Publisher** group; membership should align with business requirements.[^1]

### Office Macro Hardening Script - Prevent Activation of OLE

1. Add the script **OfficeMacroHardening-PreventActivationofOLE.ps1** as a PowerShell script using Intune Scripts.[^4]

2. Configure the script options:

| Setting | Value |
| ------- | ----- |
| Run this script using the logged on credentials | Yes |
| Enforce script signature check | No |
| Run script in 64-bit PowerShell Host | No |

3. Assign the script to a deployment group.[^4]

4. Note: This script is specifically for Office 2016 and later. A script to prevent the activation of OLE for Office 2013 is provided as **OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1**.[^4]
