## Summary

Java is not installed on Windows endpoints.[^1]

Use Microsoft Edge as the browser; Edge does not support Java applets.[^1][^2]

Security baselines indicate Java should be disabled by default in browser zones, aligning with a Java-free Edge browser.[^3]

[^1]: [Hardening user application configurations and macros (Windows endpoints)](https://blueprint.asd.gov.au/security-and-governance/system-security-plan/system-hardening-user-apps/#Hardening%20user%20application%20configurations%20and%20macros%20(Windows%20endpoints))
[^2]: [Java Runtimes with jlink](https://learn.microsoft.com/en-us/java/openjdk/java-jlink-runtimes)
[^3]: [Windows MDM security baseline settings reference for Microsoft Intune (mdm-november-2021)](https://learn.microsoft.com/en-us/intune/intune-service/protect/security-baseline-settings-mdm-all#security-baseline-for-windows,-november-2021)

## Design Decision

> [!NOTE] Java will not be installed on endpoints. Microsoft Edge will be used as the browser because it does not support Java applets.

## Prerequisites

No specific prerequisites identified in source documentation.

## Implementation Steps

### Enforce Java not installed and Edge browser (no Java applets)

1. Block Java installation on Windows endpoints.  
   This aligns with the guidance to prevent Java installation on endpoints.

2. Disable Java applets by configuring the policy Locked-Down Restricted Sites Zone Java Permissions to disable Java.  
   - Policy paths to apply:
     ```User
     ./User/Vendor/MSFT/Policy/Config/InternetExplorer/LockedDownRestrictedSitesZoneJavaPermissions
     ```
     ```Device
     ./Device/Vendor/MSFT/Policy/Config/InternetExplorer/LockedDownRestrictedSitesZoneJavaPermissions
     ```
   - Rationale: Disables Java to prevent any applets from running in restricted sites.
     - Source: Policy CSP for Internet Explorer Java permissions and Intune security baseline guidance. [^1][^2]

3. Remove Internet Explorer 11 from endpoints or disable it; ensure only Edge is allowed.  
   - Rationale: Internet Explorer 11 should be removed or disabled as part of browser hardening; Edge is the only supported browser in the baseline.  
     - Source: ASD Essential Eight guidance and security baseline references. [^3]

4. Ensure Edge is the only allowed browser and that it does not process Java from the internet.  
   - Rationale: Edge is the permitted browser, with policy controls restricting Java processing from the internet.  
     - Source: ASD Essential Eight implementation guidance. [^4]

5. Enable Edge native advertisement blocking to reduce exposure to potential malvertising vectors.  
   - Rationale: Edge advertisement blocking is part of the hardening guidance for web content handling.  
     - Source: ASD blueprint guidance. [^1]
