## Summary

Deploy a Conditional Access Policy that blocks cloud administrators from signing in unless they originate from a trusted known IP address range.[^4] This supports zero-trust administration by restricting privileged access to approved network locations.[^4] Configure Microsoft Entra ID with Intune-based Conditional Access to enforce CA for privileged access to approved networks.[^5]

[^4]: [Secure administration solutions should comprise](https://blueprint.asd.gov.au/design/platform/identity/users/#Secure-administration-solutions-should-comprise)
[^5]: [Device configuration sets](https://blueprint.asd.gov.au/design/platform/client/device-configuration/)

## Design Decision

> [!NOTE] Block cloud administrator access by enforcing a Conditional Access policy that restricts sign-ins to trusted known IP address ranges. This design ensures privileged administration is only possible from approved networks.

## Prerequisites

* **Permissions/Roles:**  
  - Separate credentials are provided for non-privileged and privileged duties. [^4]  
  - Break-glass emergency admin accounts are configured in Microsoft Entra ID with emergency access roles (e.g., Global Administrator). [^1]  
  - Administrative access is restricted to approved admin portals via jump servers or Secure Admin Workstations, with Conditional Access enforcement. [^4]  
  - Just-in-Time administration is used for privileged roles. [^6]

* **Dependencies:**  
  - Microsoft Entra ID (Azure AD) environment for identity management and break-glass accounts. [^1]  
  - Microsoft Intune / Endpoint Manager used to configure Secure Admin Workstations and device configuration, and to enforce Conditional Access. [^5][^4]  
  - Conditional Access policies to restrict privileged access, including blocking access from untrusted IP ranges. [^4]  
  - Secure Admin Workstations (SAW) and jump hosts, including network controls to limit management traffic to approved admin portals. [^4][^6]
