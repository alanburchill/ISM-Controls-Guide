## Summary

Monitor the **Service Health** in the Microsoft 365 Admin Portal to detect service vulnerability announcements.[^1]

[^1]: [Microsoft 365 vulnerability scanning and remediation](https://learn.microsoft.com/en-us/compliance/assurance/assurance-microsoft-365-vulnerability-scanning-and-remediation)

## Design Decision

Use **Microsoft 365 Admin Center** to (1) configure **Service Health alerts** and (2) deploy **Monitor-ServiceHealth.ps1** via **Microsoft Intune**.

> [!NOTE]
> Deploying **Monitor-ServiceHealth.ps1** provides ongoing visibility into Microsoft 365 service health announcements.

## Prerequisites

### Licensing
- Use **Microsoft Defender Vulnerability Management (DVM)**, or **Microsoft Defender for Endpoint Plan 2** or **E5** license to enable vulnerability management capabilities. [^1]

### Permissions/Roles
- To access the **Microsoft Defender portal** for DVM, you must be in the **Security Reader** built-in role. [^1]

### Dependencies
- Devices must be onboarded to **Defender for Endpoint**, or Defender for Endpoint must be running in block mode if not onboarded, to support DVM. [^1]

[^1]: [Essential Eight patch applications](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app)
