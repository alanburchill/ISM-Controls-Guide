## Summary

Monitor the Microsoft 365 Admin Portal "Service Health" for service vulnerability announcements and track remediation status through automated reporting in TVR. Use automated patch management to ensure timely updates across Windows and third-party software, prioritizing critical vulnerabilities. Leverage pre- and post-event patching scripts and granular maintenance configurations to coordinate patch sequencing and minimize downtime.

## Prerequisites

- **Permissions/Roles:** Roles required: Posture management; Infrastructure and endpoint security; Application Security and DevOps. [^1]

- **Dependencies:** TVR vulnerability data dashboard in Microsoft 365 [^4]; Asset inventory in TVR [^4]; Azure Update Manager patching [^6]; Pre- and post-event update scripts via Azure Arc-enabled patch management [^7]; Patching OS via Microsoft Intune and Defender for Endpoint per ASD Essential Eight guidance [^3].
