## Summary

Regularly review the detected application inventory on all devices via the Microsoft Defender admin portal to identify software that must be removed[^1]. Then use the current deployment mechanism to remove the identified applications as required[^1].

[^1]: [Manage AI on Android with Intune - A Guide for IT Admins](https://learn.microsoft.com/en-us/intune/solutions/ai/manage-ai-android#block-ai-apps)

## Implementation Steps

### Block AI apps on Android using Intune

1. Determine your organization's app strategy - Block or Allow.
   - Block strategy: No apps in the Google Play Store can be downloaded unless assigned by admins. Only apps that are assigned are available on the device. This strategy is the default for corporate owned devices.
   - Allow strategy: All apps can be downloaded unless specifically blocked by admins.
2. Implement your app strategy.
   2.1 Block strategy (default)
       2.1.1 In the Intune admin center, go to Apps > Android > Android apps.
       2.1.2 Select the app name > Properties.
       2.1.3 Make sure Assignments is not set to Required, not set to Available for enrolled devices, or not set to Available with or without enrollment.
       2.1.4 If all these options aren't set, then the app hasn't been deployed by an Intune policy. If any of these options are set, then the app is deployed. In this scenario, you can change the assignment to Uninstall to remove it from the devices.

[^1]: [Block AI apps](https://learn.microsoft.com/en-us/intune/solutions/ai/manage-ai-android#block-ai-apps)

### Samsung Knox: Allowed/Blocked Apps via Intune Custom Policy

1. Sign into the Microsoft Intune admin center.
2. Select Devices > Manage devices > Configuration > Create > New policy.
3. Enter the following properties:
   3.1 Platform: Android device administrator
   3.2 Profile type: Custom
4. Select Create.
5. In Basics, enter the following properties:
   5.1 Name: Enter a descriptive name for the profile. Name your profiles so you can easily identify them later. For example, a good profile name is Android Samsung Knox - blocks apps.
   5.2 Description: Enter a description that gives an overview of the setting, and any other important details. This setting is optional, but recommended.
6. Select Next.
7. In Configuration settings, select Add. Enter the following custom OMA-URI settings:
   - For a list of apps that are blocked from running on the device:
     7.1 Name: PreventStartPackages
     7.2 Description: Enter a description that gives an overview of the setting, and any other relevant information that can help you locate the profile. For example, use List of apps that are blocked from running.
     7.3 OMA-URI (case sensitive): ./Vendor/MSFT/PolicyManager/My/ApplicationManagement/PreventStartPackages
     7.4 Data type: String
     7.5 Value: Enter a list of the app package names you want to block. You can use ;,:, or | as a delimiter. For example, enter package1;package2;
   - For a list of apps that users are allowed to install from the Google Play store while excluding all other apps:
     7.6 Name: AllowInstallPackages
     7.7 Description: Enter a description that gives an overview of the setting, and any other relevant information that can help you locate the profile. For example, enter List of apps that users can install from Google Play.
     7.8 OMA-URI (case sensitive): ./Vendor/MSFT/PolicyManager/My/ApplicationManagement/AllowInstallPackages
