# A vulnerability scanner is used at least fortnightly to identify missing patches or updates for vulnerabilities in drivers. (ISM-1703)

## Summary

Onboard devices to Microsoft Defender for Endpoint by installing and registering the scanner on the designated devices. [^1]

Defender Vulnerability Management provides asset visibility and continuous vulnerability assessments to detect vulnerabilities across supported platforms, including drivers. [^2]

Perform vulnerability scanning at least fortnightly to identify missing patches or updates for vulnerabilities. [^3]

Open the Microsoft Defender security portal and review the Exposure management report under Vulnerabilities to identify and prioritize mitigations for unpatched vulnerabilities. [^2]

## Design Decision

> [!NOTE] Onboard devices to the endpoint protection service and monitor vulnerabilities using the security portal report under Exposure management > Vulnerabilities.

## Prerequisites

* **Dependencies:** Onboard devices to Microsoft Defender for Endpoint. [^1]
* **Dependencies:** azureADDevice ID is required to enroll devices in driver management. [^7]
* **Permissions/Roles:** The user account used to perform scanner registration must have the Defender for Endpoint permission "Manage security settings in Defender." [^1]
* **Permissions/Roles:** Windows Autopatch prerequisites must be met, including WindowsUpdates.ReadWrite.All permissions for Windows Autopatch operations. [^6]
* **Permissions/Roles:** Windows Autopatch prerequisites must be met, including Device.Read.All permission to display device information. [^6]

[^1]: [Network device discovery and vulnerability management](https://learn.microsoft.com/en-us/defender-endpoint/network-devices#scanner-installation-&-registration)
[^6]: [Windows Autopatch programmatic controls for drivers and firmware updates](https://learn.microsoft.com/en-us/windows/deployment/windows-autopatch/manage/windows-autopatch-driver-and-firmware-update-programmatic-controls)
[^7]: [Deploy a driver update using Windows Autopatch](https://learn.microsoft.com/en-us/graph/windowsupdates-manage-driver-update)

## Implementation Steps

### Onboard devices to Microsoft Defender for Endpoint

1. Copy and follow the URL that appears on the command line and use the provided installation code to complete the registration process.
2. Enter the code and sign in using a Microsoft account that has the Defender for Endpoint permission called "Manage security settings in Defender."
3. When finished, you should see a message confirming you've signed in. [^1]
