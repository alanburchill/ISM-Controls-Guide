## Summary

Onboard devices to **Microsoft Defender for Endpoint** and review the vulnerability findings in the **Microsoft Defender** security portal under **Exposure management** > **Vulnerabilities**.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight - Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Design Decision

Onboard devices to **Microsoft Defender for Endpoint** to enable vulnerability visibility, then use the **Microsoft Defender** security portal report under **Exposure management** > **Vulnerabilities** to monitor exposed devices.

> [!NOTE]
> Onboard devices to **Microsoft Defender for Endpoint** and review the **Vulnerabilities** report under **Exposure management** in the **Microsoft Defender** portal for ongoing visibility.

## Prerequisites

- **Dependencies:**
  - Onboard devices to Microsoft Defender for Endpoint. [^1]
  - Create a new Windows Configuration Profile with a type of Template>Microsoft Defender for Endpoint (desktop devices running Windows 10 or later). [^1]
  - Set telemetry reporting frequency to Enable. [^1]
  - Assign the profile to a group containing all applicable Windows devices. [^1]
  - Discovery of vulnerabilities Using Microsoft Defender Vulnerability Management. [^1]
  - In the Microsoft Security Portal under Vulnerability Management > Inventories, software products identified across endpoints onboarded to Defender for Endpoint are shown. [^1]

[^1]: [Essential Eight patch operating systems - Essential Eight - Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Implementation Steps

### Configure Policy using Settings Catalog

1. Create a new Windows Configuration Profile with a type of Template > Microsoft Defender for Endpoint for desktop devices running Windows 10 or later. [^1]

2. Configure telemetry reporting frequency to Enable using the following setting:

| Setting | Value |
| ------- | ----- |
| **Telemetry reporting frequency** | **Enable** |

3. Assign the profile to a group containing all applicable Windows devices. [^1]

4. Use **Microsoft Defender Vulnerability Management** to discover vulnerabilities. [^1]

5. In the Microsoft Security Portal under **Vulnerability Management** > **Inventories**, review software products identified across endpoints onboarded to Defender for Endpoint; this includes vendor name, weaknesses found, threats associated with them, and exposed devices. [^1]

6. On a device page, view software inventory by navigating to the **Device Inventory** page. Select the device to open the device page, then select the **Software inventory** tab to see the list of all known software. Selecting a software entry opens a flyout with more information, including corresponding security recommendations for the weaknesses and vulnerabilities, named CVEs, devices that have the software installed, and the software version list. [^1]
