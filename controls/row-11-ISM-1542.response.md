# Microsoft Office is configured to prevent activation of Object Linking and Embedding packages. (ISM-1542)

## Summary

Import the OfficeMacroHardeningPreventActivationOfOle.ps1 script via InTune Scripts to disable OLE activation in Office.[^1] Run the script using the logged-on credentials, do not enforce script signature checks, and do not run in a 64-bit PowerShell host.[^1] Assign the script to All Office Users to apply the hardening across Office installations.[^1]

[^1]: [https://learn.microsoft.com/en-us/compliance/anz/e8-macro#import-script-to-prevent-activation-of-object-linking-and-embedding-packages](https://learn.microsoft.com/en-us/compliance/anz/e8-macro#import-script-to-prevent-activation-of-object-linking-and-embedding-packages)

## Design Decision

> [!NOTE] Office OLE activation will be disabled by deploying the OfficeMacroHardeningPreventActivationOfOle.ps1 script via Intune Scripts.

## Prerequisites

* **Dependencies:** Office 2016 and later. [^1]
* **Permissions/Roles:** Script must be assigned to All Office Users. [^1]

[^1]: [Import script to prevent activation of Object Linking and Embedding packages](https://learn.microsoft.com/en-us/compliance/anz/e8-macro#import-script-to-prevent-activation-of-object-linking-and-embedding-packages)

## Implementation Steps

### Office OLE Activation Prevention via InTune Script

1. Import the PowerShell script to prevent activation of Object Linking and Embedding packages. Use the script file:
   - [OfficeMacroHardening-PreventActivationofOLE.ps1](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE.ps1).[^1]

2. Run this script using the logged on credentials: Yes.[^1]

3. Enforce script signature check: No.[^1]

4. Run script in 64-bit PowerShell Host: No.[^1]

5. Assign the PowerShell script to: All Office Users (created in Stage 1).[^1]

6. Note: This PowerShell script is specifically for Office 2016 and later. A script to prevent activation of OLE for Office 2013 is provided here:
   - [OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1).[^1]

[^1]: [Import script to prevent activation of Object Linking and Embedding packages](https://learn.microsoft.com/en-us/compliance/anz/e8-macro#import-script-to-prevent-activation-of-object-linking-and-embedding-packages)
