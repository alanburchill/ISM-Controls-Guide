## Design Decision

Use **Microsoft Defender** to regularly review the detected application inventory on all devices and use the current deployment mechanism to remove applications as required.

> [!NOTE]
> The inventory review in **Microsoft Defender** drives removal via the deployment mechanism.

## Implementation Steps

### Review Inventory in Defender Portal

1. Sign in to the Microsoft Defender portal.  
   [^1]

2. Open the Software inventory page to view installed software across devices.  
   [^1]

3. Identify apps that are obsolete or require removal based on vendor support status and organizational policy.  
   [^1]

4. If tools cannot be used, request a demonstration that shows the versions and install dates.  
   [^2]

5. Compile a removal list and prepare for deployment using the current deployment mechanism.  
   [^1]

### Remove Apps Using Current Deployment Mechanism

1. Use the current deployment mechanism to remove apps identified in the inventory review.  
   [^1]

2. Uninstall an app using Intune (if this is the chosen deployment channel):
   - Sign in to the Intune admin center.
   - Apps > All Apps > the app > Assignments > Uninstall.
   - In the Add group pane, select Included Groups to choose affected user groups.
   - Select the groups to apply the uninstall assignment.
   - Click OK to set the assignment, then Save.  
   - Important: Remove the install group assignment before uninstall to ensure removal takes effect; otherwise, the app may remain installed.  
   [^3]

3. Remove apps and configurations using the remote action in Intune:
   - Sign in to the Intune admin center.
   - Devices > All devices.
   - At the top, choose Remove apps and configuration.
   - Add items to remove, selecting either Configuration Item or App.
   - Review the list, then initiate Remove.  
   - Note: Removal actions require devices to be online and connected; interruptions may delay removal.  
   [^4]

4. Optional: Use policy-based in-box app removal for Microsoft Store apps:
   - Create a Settings Catalog policy and configure the following:
     - Category: Administrative Templates\Windows Components\App Package Deployment
