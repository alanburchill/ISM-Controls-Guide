## Summary

Patches, updates, or vendor mitigations for vulnerabilities must be applied within two weeks of release, or within 48 hours if an exploit exists[^1]. Configure and enable Windows Autopatch for all workstations via the InTune admin portal to automate this process[^1]. Use update rings in Intune to tailor deployment timing and conduct pilot testing before full rollout[^1].

[^1]: [ASD Blueprint: Windows update and patching](https://blueprint.asd.gov.au/design/endpoints/windows/configuration/windows-update-and-patching/)

## Design Decision

> [!NOTE] Windows Autopatch will be configured and enabled for all workstations via the InTune admin portal.

## Prerequisites

* **Licensing:** Microsoft Intune Plan 1 licensing at minimum for devices configured via Intune. [^1]
* **Dependencies:** Intune-based Windows Update for Business management with update rings; cloud-native deployments rely on Intune; hybrid deployments can use MECM or WSUS in addition to Intune. [^1]

[^1]: [ASD Blueprint: Windows update and patching](https://blueprint.asd.gov.au/design/endpoints/windows/configuration/windows-update-and-patching/)
