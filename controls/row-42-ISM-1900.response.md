## Summary

Onboard devices to Microsoft Defender for Endpoint; Defender Vulnerability Management continuously monitors and detects risk across devices.[^2] Use the Microsoft Defender security portal under Exposure management > Vulnerabilities to view processor/BIOS vulnerabilities and firmware-related findings, and to access remediation guidance.[^3] A vulnerability scanner is configured to run on a fortnightly cadence to identify missing patches or updates for vulnerabilities in firmware, OS, and other components.[^5]

[^2]: [Implementation with Microsoft platform](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app#implementation-with-microsoft-platform)
[^3]: [Hardware and firmware assessment](https://learn.microsoft.com/en-us/defender-vulnerability-management/tvm-hardware-and-firmware#find-processor-and-bios-vulnerabilities)
[^5]: [Patch operating systems](https://blueprint.asd.gov.au/security-and-governance/essential-eight/patch-os/)

## Design Decision

> [!NOTE] Onboard all devices to Microsoft Defender for Endpoint. Use the Defender portal's Exposure management > Vulnerabilities report for vulnerability visibility.

## Prerequisites

* **Dependencies:** Onboard devices to Microsoft Defender for Endpoint and enable Defender Vulnerability Management to monitor risk. [^1]

[^1]: [Implementation with Microsoft platform](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app#implementation-with-microsoft-platform)

## Implementation Steps

### Onboard devices to Defender for Endpoint

1. Onboard devices to Defender for Endpoint. [^1]
2. Open the Microsoft Defender security portal and view the Exposure management > Vulnerabilities report to monitor vulnerabilities. [^1]
