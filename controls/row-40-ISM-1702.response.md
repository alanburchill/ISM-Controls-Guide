## Summary

Onboard devices to Microsoft Defender for Endpoint.  
Then use the "Microsoft Defender" security portal report under "Exposure management" > "Vulnerabilities."  
Defender Vulnerability Management provides continuous asset discovery and a consolidated real-time inventory of software applications, digital certificates, hardware and firmware, and browser extensions to support vulnerability assessment and remediation.[^1][^2][^3]
