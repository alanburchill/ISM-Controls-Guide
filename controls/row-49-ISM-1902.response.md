# Patches, updates or other vendor mitigations for vulnerabilities in operating systems of workstations, non-internet-facing servers and non-internet-facing network devices are applied within one month of release when vulnerabilities are assessed as non-critical by vendors and no working exploits exist. (ISM-1902)

## Summary

Maintain a monthly patch cadence for non-critical OS updates via Intune Windows AutoPatch.[^1]

Hotpatch updates are monthly security updates that install without requiring a restart, reducing downtime and enabling faster protection.[^2]

Prerequisites include Windows 11 24H2 or later and enabled VBS to ensure secure installation of hotpatch updates.[^1][^2]

[^1]: [Hotpatch updates](https://learn.microsoft.com/en-us/windows/deployment/windows-autopatch/manage/windows-autopatch-hotpatch-updates#Hotpatch updates)
[^2]: [Deploy a hotpatch quality update using Windows Autopatch](https://learn.microsoft.com/en-us/graph/windowsupdates-hotpatch-update#Deploy a hotpatch-quality-update-using-Windows-Autopatch)

## Design Decision

> [!NOTE] Use Windows Autopatch hotpatch updates to maintain a monthly patch cadence for non-critical OS updates. Hotpatch updates install without requiring a restart, minimizing disruption while keeping devices protected.

## Prerequisites

* **Dependencies:** 
  1. Devices meet the prerequisites for Windows Autopatch. [^1]
  2. Operating System: Devices must run Windows 11 24H2 or later. [^1]
  3. VBS must be enabled to ensure secure installation of hotpatch updates. [^1]

[^1]: [Hotpatch updates](https://learn.microsoft.com/en-us/windows/deployment/windows-autopatch/manage/windows-autopatch-hotpatch-updates#Hotpatch updates)

## Implementation Steps

### Monthly patch cadence with Windows Autopatch hotpatch updates

1. Enroll devices in Windows Autopatch quality update policy via Intune.
2. Verify prerequisites: Windows 11 24H2 or later; Virtualization-Based Security (VBS) must be enabled.
3. Enable Hotpatch updates through Windows Autopatch to deploy monthly hotpatch quality updates.
4. Do not modify existing update ring configurations; the existing rings are honored alongside Hotpatch policies.
5. Onboard endpoints into Microsoft Defender for Endpoint for vulnerability management:
   5.1 Create a new Windows Configuration Profile with type Template > Microsoft Defender for Endpoint.
   5.2 Set Expedite telemetry reporting frequency to Enable.
   5.3 Assign the profile to a group containing all applicable Windows devices.
6. Monitor and verify monthly cadence and update status:
   - Use Hotpatch quality update status views to confirm deployments per policy.
7. Align patching approach with broader guidance:
   - Use update rings to define deployment windows and schedules; Intune is suitable for cloud-native deployments; ensure cadence supports timely patching per organizational risk tolerance.[^1][^2][^3][^4]
