# Office productivity suites are hardened using ASD and vendor hardening guidance, with the most restrictive guidance taking precedence when conflicts occur.

## Summary

Configure **ACSC Office HardeningGuidelinespolicy** via Intune configuration profiles and deploy the **ACSC Windows Hardening Guidelines-Attack Surface Reduction policy** and the **Macros Enabled for Trusted Publishers policy**.[^1][^2]

[^1]: [Essential Eight configure Microsoft Office macro settings](https://learn.microsoft.com/en-us/compliance/anz/e8-macro)
[^2]: [Guidelines for system hardening](https://www.cyber.gov.au/business-government/asds-cyber-security-frameworks/ism/cyber-security-guidelines/guidelines-for-system-hardening)

## Design Decision

Use **Microsoft Intune** to (1) configure **ACSC Office Hardening Guidelines policy** and (2) deploy **OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1** via **Intune configuration profiles**.

> [!NOTE]
> Deploying **OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1** complements the ACSC Office Hardening policy by preventing OLE activation in Office macros.

## Prerequisites

* **Dependencies:**
  - Graph Explorer access and authentication to retrieve and paste the ASR policy JSON.[^1]
  - ACSC Windows Hardening Guidelines Attack Surface Reduction policy JSON ready for use.[^1]
  - Access to the Microsoft Intune console to import and deploy the ASR policy (Devices > Windows > Configuration profiles > Create > Import Policy).[^3]
  - ASR policy is configured in audit mode and should be tested for compatibility before enforcement.[^1]
  - Policy assignment to All Office Users in Intune after import.[^3]

[^1]: [Essential Eight user application hardening - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)
[^3]: [Essential Eight configure Microsoft Office macro settings - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-macro)
