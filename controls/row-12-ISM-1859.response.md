## Summary

Office productivity suites are hardened using ASD and vendor hardening guidance, with the most restrictive guidance taking precedence when conflicts occur.[^1][^2] Apply ACSC Office hardening policies via Intune configuration profiles to enforce these settings across endpoints.[^2]

[^1]: [Office productivity suites](https://blueprint.asd.gov.au/security-and-governance/essential-eight/user-application-hardening/#Office-productivity-suites)
[^2]: [Hardening guidance for web browsers, Microsoft Office and PDF software](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden#hardening-guidance-for-web-browsers,-microsoft-office-and-pdf-software)

## Design Decision

> [!NOTE] Office productivity suites will be hardened using ACSC Office hardening guidelines deployed via Intune configuration profiles.

## Prerequisites

* **Dependencies:** 
  - Windows 10 and Windows 11 endpoints. [^1]
  - Microsoft Intune console access to import policies and manage configuration profiles. [^3]
  - ACSC Edge Hardening Guidelines JSON policy file saved locally for import. [^1]
  - Macros Enabled for Trusted Publishers JSON policy file saved locally for import. [^3]
  - ACSC Office hardening guidelines to deploy via policy. [^2]
  - Microsoft Edge Baseline within Intune for hardening. [^1]
  - Device Configuration Profiles can be deployed to specific users or devices by using Entra ID groups. [^9]

## Implementation Steps

### Deploy ACSC Office hardening guidelines

1. Deploy the ACSC Office hardening guidelines as part of the Essential Eight Office hardening configuration. [^1]

### Import and apply Macros Enabled for Trusted Publishers policy

2. Save the Macros Enabled for Trusted Publishers policy JSON to your local device. [Macros Enabled for Trusted Publishers.json](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/Macros%20Enabled%20for%20Trusted%20Publishers.json) [^2]

3. In the Intune console, import the policy: Devices > Windows > Configuration profiles > Create > Import Policy. [^2]

4. Name the policy, select Browse for files under Policy file, and navigate to the saved policy. [^2]

5. Select Save. [^2]

6. Assign the policy to the group: “Allow macro execution - Trusted Publisher.” [^2]

### Strengthen macro trust using Trusted Publisher guidance

7. Use Trusted Publisher to limit macro execution to a curated list of publishers; prefer Trusted Publisher over Trusted Location. [Trusted Publisher](https://learn.microsoft.com/en-us/compliance/anz/e8-macro#trusted-publisher) [^3]
