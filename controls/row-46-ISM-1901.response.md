# Patches, updates or other vendor mitigations for vulnerabilities in office productivity suites, web browsers and their extensions, email clients, PDF applications, and security products are applied within two weeks of release when vulnerabilities are assessed as non-critical by vendors and no working exploits exist.

## Summary

Configure **Windows Autopatch** for all workstations via the **Intune** admin portal and deploy **third-party application updates** using the **Intune Enterpsie Application Catalogue**; otherwise repackage and redeploy all applications that required security updates within the timeline.[^1] For the **Edge** web browser configure all devices to **Targe Channel** or **Stable**.[^2]

[^1]: [Essential Eight patch operating systems](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)
[^2]: [Essential Eight patch applications](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app)

## Design Decision

Use **Windows Autopatch** to (1) configure **Windows Autopatch enrollment for all workstations** and (2) deploy **AutopatchEnrollment.ps1** via **InTune admin portal**.

> [!NOTE]
> Deploying **AutopatchEnrollment.ps1** also configures **Edge** to **Target Channel** or **Stable**.

## Prerequisites

- **Permissions/Roles:** Global Administrator role required to enable Windows Autopatch readiness assessment; use roles with the fewest permissions; admin contacts must be defined for each area of focus.[^1]

- **Dependencies:** Microsoft Entra ID; Microsoft Intune; endpoints onboarded to Microsoft Defender for Endpoint; Defender Vulnerability Management integration with Intune to support remediation workflow.[^1][^2]

[^1]: [Autopatch enrollment steps](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)
[^2]: [Essential Eight patch applications](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-app)

## Implementation Steps

### Enable Windows Autopatch via Intune

1. In the **Intune** portal, navigate to **Windows Autopatch > Tenant enrollment** to enable the Readiness assessment.[^1]

2. Complete the Readiness assessment and verify admin contacts. In **Windows Autopatch > Admin contacts**, add the contact details for each area of focus.[^1]

3. Register devices for **Windows Autopatch** by adding them to the Windows Autopatch Device Registration group. Autopatch will manage enrollment and deployment once devices are registered.[^1]

4. Use the **Autopatch dashboard** to monitor device enrollment, deployment rings, and update status.[^1]

### Manage Third-Party Applications via Intune Application Deployment

1. Use the **Intune Application deployment method** to deploy new versions of third-party applications.[^2]

2. If a new version is not available, repackage and redeploy applications that require security updates within the defined patch window and timelines described in guidance for patching.[^3]

3. Edge browser configuration and related browser update settings are not described in the source documentation. Not provided in source documentation.
