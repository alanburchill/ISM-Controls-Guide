## Summary

Configured and enable Windows Autopatch for all workstations via the InTune admin portal. For third-party applications, deploy new versions via Intune deployment methods; otherwise, repackage and redeploy all applications that require security updates within the defined timeline. Update rings define how and when service updates are deployed to Windows devices.

## Design Decision

> [!NOTE] Windows Autopatch will be configured and enabled for all workstations via the InTune admin portal. Third-party applications will be deployed via the InTune Enterpsie Application Catalogue, repackaged and redeployed as needed for security updates; Edge will be configured to Targe Channel or Stable.

## Prerequisites

* **Dependencies:**
  1. Cloud-native deployments require Microsoft Intune for patch management; Intune is the primary option for cloud-native deployments. [^2]
  2. Use Windows Update for Business with defined update rings to install patches within two weeks of release. [^1]
  3. For patches to email clients, PDF software, and security products, deploy patches via the Intune Application deployment method. [^1]
  4. For patches to applications beyond the listed categories, Intune application deployment can be used to deploy patches within one month of release. [^1]
  5. Update rings define how and when service updates are deployed to Windows devices. [^2]
  6. Pilot testing should be conducted before full rollout (Pilot and Production). [^2]
  7. Patch cadence should align with Essential Eight guidance; OS patches within two weeks; other patches within one month. [^1]

## Implementation Steps

### Windows patch management via Intune

1. Configure Windows Update for Business in the InTune admin portal to manage patches for Windows devices. [^2]

2. Define update rings to specify how and when service updates are deployed to Windows devices. [^2]

3. Enable non-Windows updates (e.g., Microsoft Office updates) to be deployed together with Windows updates. [^2]

4. Establish patching cadence: patches should be applied within two weeks of release, or within 48 hours if an exploit exists. [^2]

5. Implement a Pilot and Production rollout approach to test updates before broad deployment. [^2]

### Third-party applications patching via Intune Application Deployment

1. For third-party applications, deploy new versions of the application via the Intune Application deployment method. [^1]
