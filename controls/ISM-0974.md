# Multi-factor authentication is used to authenticate unprivileged users of systems.

## Summary

Configure a **Conditional Access policy** in the **Microsoft Entra ID Portal** to require **multifactor authentication** for users accessing specified resources. Validate enforcement by reviewing sign-in logs per Entra MFA guidance.[^1]

[^1]: [How to verify that users are set up for mandatory Microsoft Entra multifactor authentication (MFA) - Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication)

## Design Decision

Use **Microsoft Entra ID** to (1) configure **Conditional Access policy requiring multifactor authentication** and (2) deploy **ScriptName.ps1** via Entra ID Portal.

> [!NOTE]
> Deploying **ScriptName.ps1** via Entra ID Portal enforces MFA for unprivileged users.

## Prerequisites

### Licensing
- **Microsoft Entra ID P1** or higher license is required to create and enforce Conditional Access policies that require MFA.[^1]

### Permissions/Roles
- At least a **Conditional Access Administrator** role in Microsoft Entra ID is required to create Conditional Access policies.[^1]
- Users to be targeted by MFA policies must be assigned **Microsoft Entra ID P1** or higher licenses.[^1]

[^1]: [How to verify that users are set up for mandatory Microsoft Entra multifactor authentication (MFA)](https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication)

## Implementation Steps

### Create Conditional Access policy to require MFA for all users

1. Sign in to the **Microsoft Entra admin center** as at least a **Conditional Access Administrator**. [^3]
2. Navigate to **Entra ID** > **Conditional Access** > **Policies**. [^3]
3. Select **New policy**. [^3]
4. Name the policy. [^3]
5. Under **Assignments**, select **Users or workload identities**. Under **Include**, select **All users** or a group of users who sign in to the applications that require MFA. [^3]
6. Under **Include**, ensure the intended users are selected. [^3]
7. Under **Target resources** > **Cloud apps** > **Include**, select the apps: **Microsoft Admin Portals** and **Windows Azure Service Management API**. [^3]
8. Under **Access controls** > **Grant**, select **Grant access**, check **Require multifactor authentication**, and select **Select**. [^3]
9. Confirm the settings and set **Enable policy** to **Report-only**. [^3]
10. Select **Create** to create and enable your policy. [^3]
11. After you apply, consider testing the policy in **Report-only** mode to understand impact before turning it On. [^3]

| Setting | Value |
| ------- | ----- |
| Grant controls | Require multifactor authentication |
| Cloud apps included | Microsoft Admin Portals; Windows Azure Service Management API |
| Enable mode for testing | Report-only |

> [!NOTE]
> Validate MFA coverage and impact before enabling the policy fully. [^3]

### Create Conditional Access policy to require MFA with device compliance or risk-based sign-ins

1. Sign in to the **Microsoft Entra admin center** as at least a **Conditional Access Administrator**. [^5]
2. Browse to **Entra ID** > **Conditional Access** > **Policies**. [^5]
3. Select **New policy**. [^5]
4. Name the policy. [^5]
5. Under **Assignments**, select **All users**. Optionally exclude emergency access or break-glass accounts if applicable. [^5]
6. Under **Target resources** > **Cloud apps** > **Include**, select **All cloud apps**. [^5]
7. Under **Access controls** > **Grant**, select:
   - **Require multifactor authentication**
   - **Require device to be marked as compliant** (Intune)
   - **Require Microsoft Entra hybrid joined device**  
   For multiple controls, select **Require all the selected controls**. [^5]
8. Enable the policy in **Report-only** mode for testing, then switch to On after validation. [^5]
9. Select **Create** to save the policy. [^5]

| Setting | Value |
| ------- | ----- |
| Grant controls | Require multifactor authentication; Require device to be marked as compliant; Require Microsoft Entra hybrid joined device |
| Multiple controls option | Require all the selected controls |

> [!NOTE]
> Use report-only mode to assess impact before full deployment. [^5]
