## Summary

Microsoft Office macros in files originating from the internet are blocked. Implement centralized controls to block macros from running in Office files from the Internet and enable antivirus runtime scanning of macros via AMSI, applying the policy across all Office applications. Enforce Attack Surface Reduction rules to block Win32 API calls from Office macros and restrict execution to trusted locations or digitally signed macros.

## Design Decision

> [!NOTE] Block all macro-containing file types via the Anti-Malware Threat Policy (e.g., DOCM, XLSM, PPTM).

No specific prerequisites identified in source documentation.

## Implementation Steps

### Use Anti-Malware Threat Policy to block macro-containing file types

1. Block macros from running in Office files from the Internet: Enabled for all Office applications. This blocks macros from internet-sourced documents from executing. [^2]

2. Enable Attack Surface Reduction (ASR) rules to prevent macro threats:
   - Block Office apps from injecting code into other processes. [^3]
   - Block Office applications from creating executable content. [^3]
   - Block Office applications from launching child processes. [^3]
   - Block Win32 API calls from Office macros. [^3]

3. Enable macro antivirus scanning:
   - Force Runtime AV Scan: Enabled. [^2]
   - Macro Runtime Scan Scope: Enabled for all documents. [^2]
   - Ensure Microsoft Defender Antivirus is running to support AMSI-based macro inspection. [^2]

4. Prevent users from modifying macro security settings:
   - Configure policy so macro security settings cannot be changed by users. [^1]

5. Enforce macro execution restrictions:
   - Allow macros only when running in a sandboxed environment, in trusted locations, or when digitally signed by a trusted publisher. [^1]

6. Enable macro execution logging:
   - Turn on Trust Center logging to capture macro execution attempts (successes and failures). [^4]

7. Refer to enterprise hardening guidance for additional context:
   - Review ASD Blueprint guidance on macro hardening and trusted locations as applicable to your environment. [^4][^5]
