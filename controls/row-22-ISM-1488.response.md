# Microsoft Office macros in files originating from the internet are blocked.

## Summary

Configure the **Block macros from running in Office files from the Internet** policy and deploy it across devices to block macros in Office documents obtained from untrusted sources.[^1]

[^1]: [Essential Eight configure Microsoft Office macro settings](https://learn.microsoft.com/en-us/compliance/anz/e8-macro)

## Design Decision

Use **Microsoft 365 Apps for Enterprise** to configure **Block macros from running in Office files from the Internet** and deploy **OfficeMacroHardening-PreventActivationofOLE.ps1** via **Intune**.

> [!NOTE]
> Deploying **OfficeMacroHardening-PreventActivationofOLE.ps1** also strengthens macro security.

## Prerequisites

No specific prerequisites identified in source documentation.

## Implementation Steps

### Configure Anti-Malware Threat Policy Using Settings Catalog

1. In Intune, create a Windows 10 and later configuration profile using the **Settings Catalog**.[^3]

2. Search for **Block macros from running in Office files from the Internet** and enable it. This policy blocks macros in Office files downloaded from the Internet and reduces macro-based threats.[^2][^3]

3. Save and assign the policy to the target group.[^3]

| Setting | Value |
| ------- | ----- |
| **Block macros from running in Office files from the Internet** | Enabled |

### Deploy Anti-Malware Threat Policy Using Cloud Policy (Intune)

1. In the Intune admin center, create a Cloud Policy configuration.[^3]

2. Add **Block macros from running in Office files from the Internet** to the policy configuration and assign to a deployment group.[^3]

3. Deploy the policy to devices/users.[^3]

| Setting | Value |
| ------- | ----- |
| **Block macros from running in Office files from the Internet** | Enabled |

> [!NOTE]
> Implementing macro blocking aligns with Essential Eight guidance and macro hardening practices.[^1][^4][^5]
