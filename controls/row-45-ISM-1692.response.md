# Patches, updates or other vendor mitigations for vulnerabilities in office productivity suites, web browsers and their extensions, email clients, PDF applications, and security products are applied within 48 hours of release when vulnerabilities are assessed as critical by vendors or when working exploits exist. ## Summary

Configure and enable Windows Autopatch for all workstations through the InTune admin portal to expedite quality updates and accelerate deployment of critical patches[^1]. For third-party applications, deploy updates via InTune Enterprise Application Catalogue; otherwise repackage and redeploy all applications that require security updates within the timeline[^2]. Configure all devices' Edge web browser to "Targe Channel" or "Stable" to maintain timely, stable browsing updates.

[^1]: [Expediting quality updates](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os#expediting-quality-updates#Expediting quality updates)
[^2]: [ASD Blueprint: Windows update and patching | ASD's Blueprint for Secure Cloud](https://blueprint.asd.gov.au/design/endpoints/windows/configuration/windows-update-and-patching/#windows-update-and-patching)

## Design Decision

> [!NOTE] Windows Autopatch will be configured and enabled for all workstations via the Intune admin portal, third-party applications will be deployed in the Enterprise Application Catalogue or repackaged and redeployed as needed for security updates, and Edge will be configured to "Targe Channel" or "Stable".

## Prerequisites

* **Dependencies:** Microsoft Intune is the primary patching technology for cloud-native deployments; it enables expediting quality updates and defines update rings to control deployment. For hybrid deployments, patching can be implemented with MECM or WSUS in addition to Intune; Windows Update for Business policies can manage updates. [^1][^2]

[^1]: [Expediting quality updates](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os#expediting-quality-updates#Expediting%20quality%20updates)

## Implementation Steps

### Expedite Windows quality updates via Intune

1. Create a Quality updates for Windows 10 and later profile, under Devices > Windows > Quality updates for Windows 10 and later (Preview)
2. Provide a name. It's suggested that the name of the policy aligns to the quality update version being expedited for ease of reference.
3. Define the quality updates that Windows Update for Business expedites the installation of if the device Operating System version is less than.
4. Define the number of days until a restart of the device is enforced
5. Assign the profile to a group containing all applicable Windows devices
> [!NOTE] If the number of days to wait before a restart is enforced is set to 0, the device will immediately restart upon receiving the update. The user won't receive the option to delay the reboot. [^1]
