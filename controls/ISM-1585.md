## Summary

Configure **Web browser security settings** via **Intune** and deploy them to enforce the configuration so users cannot modify them.[^1]

[^1]: [Essential Eight user application hardening - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Design Decision

Use **Microsoft Intune** to (1) configure **Web browser security settings** and (2) deploy **BrowserSecurity.ps1** via **Settings Catalog**.

> [!NOTE]
> Deploying **BrowserSecurity.ps1** also prevents standard users from changing browser settings.

## Prerequisites

- **Permissions/Roles:** An Intune administrator account with the **Policy and Profile Manager** built-in role, at minimum.[^6]

- **Dependencies:**
  - Ability to create and deploy a **Settings Catalog** policy in Intune.[^6]
  - Devices enrolled in **Microsoft Intune** and **security defaults** enabled.[^2]


[^6]: [Create a policy using settings catalog in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/configuration/settings-catalog)

[^2]: [Technical example: User application hardening](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/small-business-cyber-security/small-business-cloud-security-guide/technical-example-user-application-hardening)

## Implementation Steps

### Configure Policy using Settings Catalog

1. Sign in to the Microsoft Intune admin center. Navigate to Devices > Manage devices > Configuration > Create > New policy. Platform: Windows 10 and later. Profile type: **Settings catalog**. Then Create.[^6]

2. In Basics, name the policy and add an optional description, then select Next. In the settings picker, search for the **browser security setting** and enable it.[^6][^1]

3. In Configuration settings, add the **browser security settings** to enforce. Save the profile and assign it to target devices or users. Monitor deployment status to confirm enforcement. [^6]

| Setting | Value |
| ------- | ----- |
| Enforce browser security settings via Settings Catalog | Enabled |
