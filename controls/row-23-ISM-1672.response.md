## Summary

Microsoft Office macro hardening is implemented by enabling antivirus scanning of macros, blocking macros from the Internet, and preventing users from changing macro settings.[^4]

In Intune, enable the Office security setting to scan macros in Office files and set Macro Runtime Scan Scope to All documents.[^2]

Import the ACSC Office Hardening policy into Intune by saving the policy locally and importing it under Devices > Windows > Configuration profiles > Import Policy, then assigning it to the group used for trusted-publisher macro execution.[^1]

ASD guidance supports restricting macros to digitally signed publishers and enabling Defender for Endpoint to centrally store EDR logs as part of macro hardening.[^3][^4]

## Implementation Steps

### Import ACSC Office Hardening Policy via Intune

1. Save the Macros Enabled for Trusted Publishers policy to your local device.  
   [https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/Macros%20Enabled%20for%20Trusted%20Publishers.json](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/Macros%20Enabled%20for%20Trusted%20Publishers.json)[^1]

2. Navigate to the Microsoft Intune console.  
   [https://aka.ms/in](https://aka.ms/in)[^1]

3. Import a policy, under Devices > Windows > Configuration profiles > Create > Import Policy.  
   This is the Intune workflow referenced for importing a policy[^1].

4. Name the policy, select Browse for files under Policy file and navigate to the saved policy (from step 1).  
   Refer to the policy import steps in the source[^1].

5. Select Save.  
   See the Import Policy workflow described in the source[^1].

6. Assign the policy to the group: “Allow macro execution - Trusted Publisher.”  
   Alignment with the ACSC policy import steps[^1].

[^1]: [Macros Enabled for Trusted Publishers](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/Macros%20Enabled%20for%20Trusted%20Publishers.json)

### Enable Office Macro Security and Scan via Intune

1. Configure Microsoft Office Security Settings to enable antivirus scanning of Microsoft Office macros.  
   This aligns with Essential Eight macro security guidance that antivirus scanning of macros is enabled[^3].

2. Set Macro Runtime Scan Scope to Enable for all documents.  
   This configuration is described in the ASD blueprint as part of Microsoft Office Security Settings for macro hardening[^2].

3. Enable Automation Security: Enabled (Use application macro security level).  
   This is part of the Office Security Settings configuration referenced in the ASD guidance[^2].

4. Block macros from running in Office files from the Internet: Enabled.  
   This setting is part of the Office macro hardening configuration described in ASD guidance[^2].

5. Save and apply the policy to the target devices/groups.  
   Ensure the Intune profile is deployed to the appropriate stanzas as per your environment.

6. Verify macro scanning and hardening outcomes.  
   See the ASD guidance on macro hardening and macro security in Office applications for verification considerations[^2][^3].
