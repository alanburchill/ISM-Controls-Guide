# Web browsers do not process Java from the internet.

## Summary

Ensure **Java** is not installed and use **Edge** browser which does not support **Java applets**.[^1][^2]

[^1]: [Guidelines for system hardening](https://www.cyber.gov.au/business-government/asds-cyber-security-frameworks/ism/cyber-security-guidelines/guidelines-for-system-hardening)

[^2]: [Essential Eight user application hardening - Essential Eight](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Design Decision

Use **Microsoft Edge** as the primary browser and remove **Java** from endpoints to meet ISM-1486 requirements and prevent Java applets from running.

> [!NOTE]
> The decision is to use **Microsoft Edge** and remove **Java** to prevent Java applets from running.

## Prerequisites

- **Licensing:** If Intune is used to configure devices, Microsoft Intune Plan 1 licensing is required at minimum.[^1]
- **Dependencies:** Ability to create and deploy a **Settings Catalog** policy; access to **UserApplicationHardening-RemoveFeatures.ps1**.[^1]

[^1]: [Essential Eight user application hardening](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Implementation Steps

### Disable Internet Explorer 11 as a standalone browser using Settings Catalog

1. Create a new **Settings Catalog** policy.[^5]

2. Browse by category and search for **Disable Internet Explorer 11 as a standalone browser (User)** policy. Enable the setting.[^5]

3. Deploy the policy to a set of devices or users.[^5]

4. Additionally, configure the **Java permissions** policy setting to disable Java applets. Search for the policy setting and enable it to disable Java applets. This aligns with the requirement to ensure Java is not executed in the browser.[^1][^2]

5. Deploy the policy to ensure Edge is used as the primary browser for users. This aligns with using a browser that does not process Java applets.[^5]

> [!NOTE]
> This script also disables **.NET Framework 3.5 (includes .NET 2.0 and 3.0)** and **Windows PowerShell 2.0** as part of the hardening steps.

### Remove Internet Explorer 11 using Intune Scripts

1. Add **UserApplicationHardening-RemoveFeatures.ps1** as a PowerShell script using Intune **Scripts**.[^5]

2. Configure the script with the following options:[^5]

| Setting | Value |
| ------- | ----- |
| Run this script using the logged on credentials | No |
| Enforce script signature check | No |
| Run script in 64-bit PowerShell Host | No |

3. Assign the script to a deployment group.[^5]

> [!NOTE]
> This script also disables **.NET Framework 3.5 (includes .NET 2.0 and 3.0)** and **Windows PowerShell 2.0**.
