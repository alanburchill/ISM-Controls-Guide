# Multi-factor authentication is used to authenticate privileged users of systems.

## Summary

Configure **Multifactor authentication** for privileged users via the **Entra ID Portal** by creating a **Conditional Access policy** that requires MFA for selected directory roles.[^1]

[^1]: [Require MFA for administrators with Conditional Access - Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-old-require-mfa-admin)

## Design Decision

Use **Microsoft Entra ID** to configure **Conditional Access policy requiring multifactor authentication** for the intended users via the **Entra ID Portal**.

> [!NOTE]
> Deploying the policy via the Entra ID Portal enforces MFA for targeted user groups.

## Prerequisites

- **Licensing:** Microsoft Entra ID **P1** licenses are required for Conditional Access policies; included with Microsoft 365 E3 and E5.[^1]

- **Permissions/Roles:** A **Conditional Access Administrator** must be assigned to create and manage Conditional Access policies in the Entra ID admin center.[^2]

[^1]: [Step 3: Protect your Microsoft 365 user accounts - Microsoft 365 Enterprise](https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-secure-sign-in?view=o365-worldwide)

[^2]: [Require MFA for administrators with Conditional Access - Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-old-require-mfa-admin)

## Implementation Steps

### Create Conditional Access policy requiring multifactor authentication for administrators

1. Sign in to the Microsoft In Entra admin center as a user with the **Conditional Access Administrator** role. [^1]
2. Browse to Entra ID > Conditional Access > Policies. [^1]
3. Click **New policy**. [^1]
4. Name your policy. Use a meaningful name, e.g., **Require MFA for Administrators**. [^1]
5. UnderAssignments, selectUsers or workload identities. UnderInclude, selectDirectory roles and choose at least the administrator roles. [^1]
6. UnderExclude, selectUsers and groups and choose your organization’s emergency access or break-glass accounts. [^1]
7. UnderTarget resources > Resources (formerly cloud apps) > Include, select All resources (formerly All cloud apps). [^1]
8. UnderAccess controls > **Grant**, select **Grant access**, and check **Require multifactor authentication**, then click OK. [^1]
9. Confirm your settings and set **Enable policy** to **Report-only**. [^1]
10. Click **Create** to create the policy. After creation, move the **Enable policy** toggle from **Report-only** to **On**. [^1]

| Setting | Value |
| ------- | ----- |
| Grant access | **Require multifactor authentication** |

> [!NOTE]
> This approach enforces MFA for administrator sign-ins and aligns with recommended conditional access practices. [^1]

### Create Conditional Access policy requiring phishing-resistant MFA for Microsoft Entra administrator roles

1. Sign in to the Microsoft Entra admin center as a user with the **Conditional Access Administrator** role. [^2]
2. Browse to Entra ID > Conditional Access > Policies. [^2]
3. Click **New policy**. [^2]
4. Name your policy. Use a meaningful name, e.g., **Phishing-Resistant MFA for Admin Roles**. [^2]
5. UnderAssignments, selectDirectory roles and include at least the administrator roles. Exclude emergency access or break-glass accounts. [^2]
6. UnderTarget resources > Resources (formerly cloud apps) > Include, select All resources.
