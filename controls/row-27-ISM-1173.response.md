## Summary

This control describes creating a conditional access policy in Entra ID Portal to require multifactor authentication for users accessing applications that require MFA. Sign in to the Entra admin center as a Conditional Access Administrator, navigate to Entra ID > Conditional Access > Policies, create a New policy, name it, configure Assignments (Users or workload identities) and Include (All users or a group), select target resources > Cloud apps > Include (Microsoft Admin Portals and Windows Azure Service Management API), and configure Access controls > Grant, Require authentication strength, and Multifactor authentication. [^1]

[^1]: [https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication#verify-mfa-enablement](https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication#verify-mfa-enablement)

## Design Decision

> [!NOTE] A Conditional Access policy in Microsoft Entra ID will be created to require multifactor authentication for users accessing applications that require MFA. The policy will be scoped to the intended users or groups.

## Prerequisites

* **Licensing:** Microsoft Entra ID P1 or P2 license is required to create a Conditional Access policy that requires MFA. [^1]
* **Permissions/Roles:** A Conditional Access Administrator role is required to configure Conditional Access policies. [^1]

[^1]: [How to verify that users are set up for mandatory MFA](https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication#verify-mfa-enablement)

## Implementation Steps

### Create conditional access policy requiring multifactor authentication

1. Sign in to the Microsoft Entra admin center as at least a Conditional Access Administrator. [^1]
2. Browse to Entra ID > Conditional Access > Policies. [^1]
3. Select New policy. [^1]
4. Give your policy a name. We recommend that organizations create a meaningful standard for the names of their policies. [^1]
5. Under Assignments, select Users or workload identities. [^1]
6. Under Include, select All users, or a group of users who sign in to the applications that require MFA. [^1]
7. Under Target resources > Cloud apps > Include, Select apps, select Microsoft Admin Portals and Windows Azure Service Management API. [^1]
8. Under Access controls > Grant, select Grant access, Require authentication strength, select Multifactor authentication, and select Select. [^1]

[^1]: [How to verify that users are set up for mandatory MFA](https://learn.microsoft.com/en-us/entra/identity/authentication/how-to-mandatory-multifactor-authentication#verify-mfa-enablement)
