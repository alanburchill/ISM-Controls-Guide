## Summary

Configure **VBA Macro Notification Settings** via Intune policy and deploy **OfficeMacroHardening-PreventActivationofOLE.ps1** using Intune policy deployment to allow macros only when signed by a trusted publisher on a targeted device group, while excluding these members from other macro-blocking policies. [^1]

[^1]: [Essential Eight configure Microsoft Office macro settings - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-macro)

## Design Decision

Use **Intune** to configure **VBA Macro Notification Settings** and deploy **ScriptName.ps1** via **Intune policy deployment**.

> [!NOTE]
> Deploying **ScriptName.ps1** also excludes the **Allow macro execution - Trusted Publisher** group from other macro blocking policies to avoid conflicts.

## Prerequisites

### Permissions/Roles
- Create a dedicated group named **Allow macro execution - Trusted Publisher** for users who can run macros signed by a trusted publisher. This group must be excluded from the policy that blocks macros to avoid conflicts. [^1]
- Centrally manage trusted publishers. The public code-signing certificate used to sign the macros must be added to the Trusted Publishers certificate store on devices. [^3]
- Macros must be digitally signed by a trusted publisher; the code-signing certificate needs to be installed on devices. [^3]

### Dependencies
- Access to policy deployment tooling to create and deploy macro policies (Intune or Group Policy). See guidance for deploying policies via Cloud Policy or Settings Catalog as applicable. [^2]
- Ability to create and deploy a policy that disables all macros by default, and excludes the **Allow macro execution - Trusted Publisher** group. [^1]
- Ability to distribute the trusted publisher certificate to devices via Group Policy; or manual/certutil-based distribution if Group Policy is not used. [^3]

## Implementation Steps

### Create Separate Policy for Trusted Publisher Macros (Intune)

1. Create a new device group in Azure AD named **Allow macro execution - Trusted Publisher** and add devices that should run macros signed by a trusted publisher.[^4]

2. Create a policy named **All Macros Disabled** and target it to all Office users. Exclude the **Allow macro execution - Trusted Publisher** group from this policy to avoid conflicts.[^4]

3. Create a second policy targeted to the **Allow macro execution - Trusted Publisher** group that enables only digitally signed macros. In this policy, configure the following:
   - Under the setting **VBA Macro Notification Settings**: Enable and choose options to disable all except digitally signed macros, and require macros to be signed by a trusted publisher. This ensures only macros signed by a trusted publisher execute.[^3]

4. Distribute the trusted publisher certificate to devices:
   - The public code-signing certificate used to sign the macros must be installed in the device's Trusted Publishers store. Distribution can be performed via policy or scripted deployment as appropriate.[^3]

5. Validate policy effectiveness:
   - Verify that macros signed by the trusted publisher execute on devices in the **Allow macro execution - Trusted Publisher** group, while macros from untrusted sources are blocked. Macros from the internet are blocked by default.[^2][^7]

> [!NOTE]
> The separate policy approach aligns with governance guidance to isolate trusted-publisher macro execution from general macro-blocking policies to avoid conflicts.[^4][^7]

### Enforce Office Macro Settings via Intune Security Baseline

1. Use the Intune security baseline for Microsoft 365 Apps to configure macro-related Office settings:
   - Block macros from running in Office files from the Internet.
   - Enable **VBA Macro Notification Settings** and configure it to require digitally signed macros.
   - Require macros to be signed by a trusted publisher.
   These baseline settings support reducing macro risk while enabling trusted-publisher workflows.[^5]

2. For exceptions that must run macros signed by a trusted publisher, create a separate policy that targets only devices in the **Allow macro execution - Trusted Publisher** group and enables only digitally signed macros:
   - Configure the same trusted-publisher macro settings as in the first method but scoped to the exception group.[^3][^4]

3. Distribute the trusted publisher certificate to devices:
   - Import the macro signing certificate into the Trusted Publishers store on devices. Distribution can be performed via policy or scripting as appropriate.[^3]

4. Exclude members of the exception group from other macro-blocking policies to avoid conflicts:
   - Ensure the exception group is excluded from broader macro-blocking Intune policies. This separation prevents policy conflicts and aligns with recommended practice for trusted publisher macros.[^4]

5. Validate baseline effectiveness:
   - Confirm thatOffice macros from untrusted sources remain blocked, while macros signed by the trusted publisher execute for devices in the exception group. Cross-check that internet-originating macros remain blocked by default.[^2][^5]
