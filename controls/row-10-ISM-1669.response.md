## Summary

Enable the Attack Surface Reduction (ASR) rule in Intune to block Office applications from injecting code into other processes[^1]. Configure the setting "Block Office applications from injecting code into other processes" to enforce blocking; the default is off[^1]. If non-blocking monitoring is desired, use Audit mode or Warn as appropriate[^1].

[^1]: [Attack surface reduction policy settings for endpoint security in Intune](https://learn.microsoft.com/en-us/intune/intune-service/protect/endpoint-security-asr-profile-settings#attack-surface-reduction-mdm)
