## Summary

Enable an Edge policy via the Intune security baseline to block intrusive web ads.[^1] Create an Edge settings profile in Intune using the Settings Catalog for Windows 10 and later and configure Edge settings to enforce ad-blocking across devices.[^1] Edge native ad-blocking (BlockAds) is enabled by default as part of the recommended Edge hardening configuration.[^4]

[^1]: [Configure Microsoft Edge policy settings in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/configuration/settings-catalog-configure-edge#create-a-policy-for-microsoft-edge)
[^4]: [ASD Blueprint: Microsoft Edge hardening - ASD's Blueprint for Secure Cloud](https://blueprint.asd.gov.au/design/endpoints/windows/security/edge-hardening/)

## Design Decision

> [!NOTE] Enable Edge policy to block intrusive ads using the Intune security baseline.

## Prerequisites

- **Permissions/Roles:** Access to the Microsoft Intune admin center to create and manage Edge policy using the Settings Catalog. [^1]

- **Dependencies:** 
  1. Intune service and admin center are required to configure Edge policy using the Settings Catalog. [^1]
  2. Target devices must be macOS or Windows 10 and later. [^1]
  3. The policy configuration uses the Settings Catalog profile type. [^1]

[^1]: [Create a policy for Microsoft Edge](https://learn.microsoft.com/en-us/intune/intune-service/configuration/settings-catalog-configure-edge#create-a-policy-for-microsoft-edge)
