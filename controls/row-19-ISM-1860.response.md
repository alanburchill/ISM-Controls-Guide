## Summary

Configure **Vendor PDF hardening settings** via **Intune configuration profiles** to enforce the most restrictive guidance between ASD and vendor hardening guidance under **ISM-1860** requirements.[^1][^2][^3]

[^1]: [Guidelines for system hardening](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/ism/cyber-security-guidelines/guidelines-system-hardening)

[^2]: [Essential Eight user application hardening - Essential Eight](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

[^3]: [ASD Blueprint: User application hardening](https://blueprint.asd.gov.au/security-and-governance/system-security-plan/system-hardening-user-apps/)

## Design Decision

Use **Microsoft Intune** to (1) configure **Vendor PDF hardening settings** and (2) deploy **PDF_Hardening.ps1** via **Intune configuration profiles**.

> [!NOTE]
> Deploying **PDF_Hardening.ps1** through **Intune configuration profiles** enforces vendor PDF hardening guidance.

## Prerequisites

- **Permissions/Roles:** Ability to create and modify **Attack Surface Reduction** policies in **Intune Endpoint Security**.[^1]

- **Dependencies:** Access to **Microsoft Intune** with the ability to create and deploy configuration profiles, including **Attack Surface Reduction** policies. Where available, use the modern **Settings Catalogue** profile type for applying settings.[^2]

[^1]: [Essential Eight user application hardening - Essential Eight](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

[^2]: [ASD Blueprint: Device configuration](https://blueprint.asd.gov.au/design/platform/client/device-configuration/)

## Implementation Steps

### Configure PDF Hardening via Attack Surface Reduction in Intune

Vendor PDF hardening aligns with the Guidelines for system hardening[^1].

1. In the Microsoft Intune admin center, navigate to Endpoint Security > Attack Surface Reduction. [^2]
2. Create or modify an **Attack Surface Reduction** policy. [^2]
3. Set **Block Adobe Reader from creating child processes** to Enable. [^2]

| Setting | Value |
| ------- | ----- |
| **Block Adobe Reader from creating child processes** | **Enable** |

4. Assign the policy to the target group. [^2]

> [!NOTE]
> PDF viewing can be further hardened with policies included for ACSC or vendor hardening guidance for web browsers. [^2]
