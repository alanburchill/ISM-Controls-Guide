## Summary

PDF applications are hardened using ASD guidance and vendor hardening guidance, with the most restrictive guidance taking precedence when conflicts occur.[^1][^6]

Apply vendor PDF hardening settings via Intune configuration profiles, using device configuration profiles deployed to Entra ID groups to enforce the policy and manage potential conflicts.[^3][^4][^5]

[^1]: [https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden#hardening-guidance-for-web-browsers,-microsoft-office-and-pdf-software](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden#hardening-guidance-for-web-browsers,-microsoft-office-and-pdf-software)
[^3]: [Create a device configuration profile in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/configuration/device-profile-create#prerequisites)
[^4]: [Manage device security with endpoint security policies in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/protect/endpoint-security-policy#manage-policy-conflicts)
[^5]: [Device configuration](https://blueprint.asd.gov.au/design/platform/client/device-configuration/#Device configuration)
[^6]: [Hardening user applications configurations and macros (Windows endpoints)](https://blueprint.asd.gov.au/security-and-governance/system-security-plan/system-hardening-user-apps/)

## Design Decision

> [!NOTE] Vendor PDF hardening settings will be applied via Intune configuration profiles. This provides centralized, policy-driven enforcement aligned with vendor guidance.

## Prerequisites

* **Permissions/Roles:** Sign into the Intune admin center with the Policy and Profile manager role. Enroll devices in Intune. [^1]

[^1]: [Create a device configuration profile in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/configuration/device-profile-create#prerequisites)

## Implementation Steps

### Vendor PDF hardening settings via Intune configuration profiles

1. Save the ACSC Microsoft Edge Hardening Guidelines policy to your local device.[^1]
2. Navigate to the Microsoft Intune console.[^1]
3. Import a policy, under *Devices > Windows > Configuration profiles > Create > Import Policy*.[^1]
4. Name the policy, select Browse for files under Policy file and navigate to the saved policy from step 1.[^1]
5. Select Save.[^1]

> Note: Microsoft has also released Intune policies that were put together to help organizations comply with the Australian Cyber Security Centre's (ACSC) Windows Hardening Guidelines. The ACSC recommended hardening policies for Microsoft Edge are also contained within these policies.[^1]

[^1]: [Hardening guidance for web browsers, Microsoft Office and PDF software](https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden#hardening-guidance-for-web-browsers,-microsoft-office-and-pdf-software)
