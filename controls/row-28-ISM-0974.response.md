## Summary

1. Create a Conditional Access policy in Entra ID that requires multifactor authentication for all users.[^1]
2. Sign in to the Entra ID admin center as a Security Administrator, navigate to Conditional Access > Policies, select New policy from template, choose the Secure foundation template, select the option to require multifactor authentication for all users, then Review + Create and set the policy to On.[^1][^2]
3. Adjust MFA exclusions as recommended, keeping emergency access accounts excluded from MFA.[^1]

## Design Decision

> [!NOTE] Implement a Conditional Access policy in Entra ID Portal that enforces multifactor authentication for access to sensitive resources.

## Prerequisites

* **Licensing:** Microsoft Entra ID P2 or Microsoft Entra Suite license is required for full access to Microsoft Entra ID Protection features, including modifying the MFA registration policy. [^6]

* **Permissions/Roles:** Security Administrator is the minimum role required to create or edit MFA/Conditional Access policies; Authentication Administrator is required to enable per-user MFA. [^3][^2][^4]

* **Dependencies:** Access to the Microsoft Entra admin center with an appropriate admin role (e.g., Security Administrator) to configure Conditional Access and MFA policies. [^4]

## Implementation Steps

### Create Conditional Access policy requiring MFA in Entra ID Portal

1. Sign in to the Microsoft Entra admin center as at least a Security Administrator.[^1]

2. Navigate to Conditional Access > Policies.[^2]

3. Click New policy from template.[^2]

4. On the New policy from template page, verify the Select a template tab is selected and the Secure foundation tab is selected.[^2]

5. On the Secure foundation tab, select one of the required templates (for example, Require multifactor authentication for all users), and then select Review + Create.[^2]

6. On the Review + Create tab, configure the following settings:
   - Basics: Policy name (default name or customize); Policy state On.[^2]
   - Assignments: Users and groups; Excluded users value Current user and cannot be changed. Only emergency access accounts should be excluded from MFA.[^2]

7. After you finish, select Create to enable the policy. The policy you created appears on the Conditional Access | Policies page.[^2]

8. Repeat the previous steps for remaining templates as needed.[^2]

9. Adjust MFA exclusions. By default, the Conditional Access policies contain exclusions for the account you were signed in as, and you cannot modify exclusions during policy creation. It is recommended to have at least two emergency access admin accounts excluded from MFA.[^2]
