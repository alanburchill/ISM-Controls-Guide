## Summary

Onboard devices to Microsoft Defender for Endpoint and use the Defender security portal report under Exposure management > Vulnerabilities for ongoing visibility and risk-based remediation.[^1]

Vulnerability scanning is automated and continuously surfaces results in centralized dashboards to track remediation progress.[^6]

## Design Decision

> [!NOTE] Devices will be onboarded to Microsoft Defender for Endpoint, and vulnerability visibility will be obtained from the Defender portal's Exposure management > Vulnerabilities report.

## Prerequisites

- **Dependencies:** 
  1. Microsoft Defender for Endpoint security agent is installed on target devices. [^6]
  2. Devices are onboarded to Defender for Endpoint. [^1]
  3. Daily vulnerability scans are scheduled via Defender Vulnerability Management (integrated vulnerability scanning). [^6]
  4. Scan results are collected in a secure, central storage service and surfaced for reporting. [^6]
  5. Microsoft Defender vulnerability and exposure management reporting dashboards (Exposure management) are available for remediation tracking. [^7]

- **Permissions/Roles:** 
  1. Users must have the "Manage security settings in Defender" permission to configure scan jobs. [^3][^9]

## Implementation Steps

### Onboard devices to Defender for Endpoint and access Vulnerabilities report

1. Onboard devices to Defender for Endpoint. [^1]

2. Ensure Defender Vulnerability Management is enabled to continuously monitor risk across devices. [^1]

3. Open the Microsoft Defender security portal. Navigate to Exposure management > Vulnerabilities to view the vulnerabilities report. [^2]

4. Review vulnerabilities and prioritize remediation based on asset criticality and vulnerability severity. [^2]

5. Track remediation progress using the Defender Vulnerability Management dashboards and reports. [^2]

6. If using Microsoft 365 vulnerability scanning, review the TVR dashboard for live vulnerability metrics and remediation status. [^3]
