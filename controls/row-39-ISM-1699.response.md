## Summary

Onboard devices to **Microsoft Defender for Endpoint**.[^1] Then use the **Microsoft Defender** security portal report under **Exposure management** > **Vulnerabilities**.[^2]

[^1]: [Essential Eight patch operating systems - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Design Decision

Use **Microsoft Defender for Endpoint** to onboard devices and enable **Defender Vulnerability Management**, so vulnerabilities are surfaced in the **Microsoft Defender** security portal under Exposure management > Vulnerabilities.

> [!NOTE]
> Onboarding devices enables vulnerability visibility in the Defender portal under Exposure management > Vulnerabilities.

## Prerequisites

- **Licensing:** Microsoft Intune Application Management is part of Intune Suite requires an additional license.[^5]

- **Dependencies:** Endpoints must be onboarded to Microsoft Defender for Endpoint; there are additional prerequisites for using Defender Vulnerability Management (DVM).[^4]

## Implementation Steps

### Onboard devices to Microsoft Defender for Endpoint

1. Onboard endpoints to Microsoft Defender for Endpoint.[^1]

2. Create a new Windows Configuration Profile with a type of **Template > Microsoft Defender for Endpoint** for Windows 10 or later devices.[^1]

3. Configure the profile with the following options:

| Setting | Value |
| ------- | ----- |
| Profile type | **Template > Microsoft Defender for Endpoint** |
| Telemetry reporting frequency | **Enable** |
| Assigned to group | **A group containing all applicable Windows devices** |

4. Assign the profile to a group containing all applicable Windows devices.[^1]

### Review vulnerabilities in the Microsoft Defender security portal

1. Open the Microsoft Defender portal.[^2]

2. Navigate to **Exposure management** > **Vulnerabilities**.[^2]

3. Review vulnerability findings and remediation recommendations provided by Defender Vulnerability Management.[^2]
