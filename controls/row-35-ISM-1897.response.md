# Remote Credential Guard functionality is enabled.

## Summary

Configure **Remote Credential Guard** via the **Microsoft Defender for Endpoint baseline** in Intune and apply the policy to all devices.[^1]

[^1]: [Remote Credential Guard - Microsoft Learn](https://learn.microsoft.com/en-us/windows/security/identity-protection/remote-credential-guard)

## Design Decision

Use **Microsoft Defender for Endpoint baseline** to configure **Remote host allows delegation of nonexportable credentials** and deploy via **Intune/MDM** to all devices.

> [!NOTE]
> The policy is applied to all enrolled devices via **Intune/MDM**.

## Prerequisites

### Permissions/Roles
- Access to **Microsoft Intune** to create and deploy a **Settings Catalog policy**. [^1]
- Ability to assign the policy to a group containing devices or users to configure. [^1]

### Dependencies
- Availability of **Settings Catalog policy** creation in Intune to configure credentials delegation. [^1]
- Ability to configure devices using a **custom policy with Policy CSP**. [^1]
- Ability to configure devices via **Group Policy** using the Local Group Policy Editor. [^1]
- Ability to configure devices via **Registry** edits for credentials delegation. [^1]

[^1]: [Remote Credential Guard](https://learn.microsoft.com/en-us/windows/security/identity-protection/remote-credential-guard)

## Implementation Steps

### Configure Remote Credential Guard using Settings Catalog

1. Create a new **Settings Catalog** policy in Intune.[^1]
2. In the policy, configure the setting: path = Administrative Templates > System > Credentials Delegation; setting = **Remote host allows delegation of nonexportable credentials**; value = **Enabled**.[^1]
3. Assign the policy to a group that contains all devices or users to configure.[^1]

| Setting | Value |
| ------- | ----- |
| Remote host allows delegation of nonexportable credentials | Enabled |

### Configure Credential Guard using Endpoint Protection Profile

1. Create an Intune **Endpoint protection** profile for Windows devices and configure **Microsoft Defender Credential Guard** to enabled.[^3]
2. Configure the Credential Guard mode using one of the supported options: Disable; Enable with UEFI lock; Enable without UEFI lock.[^3]

| Setting | Value |
| ------- | ----- |
| Credential Guard mode | Disable; Enable with UEFI lock; Enable without UEFI lock |

3. Assign the Endpoint protection policy to the group containing all devices.[^1]

> [!NOTE]
> The policy is implemented using Microsoft Defender Credential Guard settings in Intune and should be applied to all devices. 

[^1]: [Remote Credential Guard | Microsoft Learn](https://learn.microsoft.com/en-us/windows/security/identity-protection/remote-credential-guard)
