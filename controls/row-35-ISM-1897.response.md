## Summary

Remote Credential Guard is enabled to protect credentials on Windows endpoints.[^1] The setting is implemented via the Defender for Endpoint baseline security baseline in Microsoft Intune, and the policy is applied to all devices.[^4][^7] Configure devices in Intune using the Windows security baseline to turn on Credential Guard and assign the policy to the Windows 10 and later group.[^4][^7]

[^1]: [Remote Credential Guard](https://learn.microsoft.com/en-us/windows/security/identity-protection/remote-credential-guard#remote-credential-guard)
[^4]: [Security Baseline for Windows, August 2020](https://learn.microsoft.com/en-us/intune/intune-service/protect/security-baseline-settings-mdm-all#security-baseline-for-windows,-august-2020)
[^7]: [Security baseline for Windows 10 and later](https://blueprint.asd.gov.au/configuration/intune/endpoint-security/security-baselines/security-baseline-for-windows-10-and-later/)

## Design Decision

> [!NOTE] Implement the setting using the Microsoft Defender for Endpoint baseline in Intune and apply it to all devices. This ensures centralized, uniform enforcement across the fleet.

## Prerequisites

* **Permissions/Roles:** Assign the policy to a group that contains as members the devices or users that you want to configure. [^1]

* **Dependencies:** Microsoft Intune is used to configure devices via MDM and apply the Windows security baseline; assign the baseline to appropriate groups (e.g., grp-windows10-users). [^1][^7]

[^1]: [Remote Credential Guard](https://learn.microsoft.com/en-us/windows/security/identity-protection/remote-credential-guard#remote-credential-guard)
[^7]: [Security baseline for Windows 10 and later](https://blueprint.asd.gov.au/configuration/intune/endpoint-security/security-baselines/security-baseline-for-windows-10-and-later/)

## Implementation Steps

### Microsoft Defender for Endpoint baseline in Intune

1. In Intune, apply the Security Baseline for Windows 10 and later to all managed devices. [^7]

2. Enable Credential Guard by configuring the baseline. Baseline default: Enable with UEFI lock. [^4]

3. If configuring via Intune Settings Catalog policy, configure the following settings:
   - Turn On Virtualization Based Security
     - OMA-URI: `./Device/Vendor/MSFT/Policy/Config/DeviceGuard/EnableVirtualizationBasedSecurity`
     - Data type: int
     - Value: 1
   - Credential Guard Configuration
     - OMA-URI: `./Device/Vendor/MSFT/Policy/Config/DeviceGuard/LsaCfgFlags`
     - Data type: int
     - Value: 1 (Enabled with UEFI lock)
   After applying the policy, restart the device. [^1]

4. Assign the policy to a group containing the devices/users to configure. Example: grp-windows10-users. [^7] [^1]

5. Restart the devices after policy application. [^1]
