## Implementation Steps

### Deploy Microsoft Edge security baseline - Level 2 using Intune

1. Open the Microsoft Intune admin center.[^3]
2. Navigate to Endpoint security > Security baselines > Security Baseline for Microsoft Edge > Create policy.[^3]
3. On the Basic tab, set Name to **Microsoft Edge Security Baseline - Level 2** and add a description that aligns with organizational requirements.[^3]
4. In Configuration settings, expand **Microsoft Edge** and review the preconfigured settings; you can accept defaults or customize specific settings based on organizational requirements.[^3]
5. Click Next and review the scope tags and assignments; assign the policy to the appropriate group(s).[^3]
6. Confirm the policy creation and monitor deployment status in the Intune console.[^3]
7. This approach aligns with Essential Eight guidance for Edge hardening.[^2]

### Configure Edge cookies using Settings Catalog in Intune

1. Create a new **Settings Catalog** policy in Intune.[^1]
2. Configure the **AllowCookies** setting to 1 (Block only cookies from third party websites).[^1]

| Setting | Value |
| ------- | ----- |
| **AllowCookies** | 1 (Block only cookies from third party websites) |

3. Deploy the policy to target devices or users.[^1]

> [!NOTE]
> The following action is intended to complement Edge baseline deployment with cookie hardening via Settings Catalog.[^1]
