## Summary

Backups of data, applications and settings are performed and retained in accordance with business criticality and business continuity requirements.  
Windows devices are enrolled for backup by enabling Windows Backup and Restore and turning on the Show restore page.[^1]  
Broader Microsoft 365 backup guidance covering SharePoint, Exchange Online, and OneDrive is described in the implementation guidance but not detailed in the source documentation (Not provided in source documentation).

[^1]: [RBAC and tenant wide targeting for Windows Backup and Restore enrollment](https://learn.microsoft.com/en-us/intune/intune-service/enrollment/windows-backup-restore#rbac-and-tenant-wide-targeting)

## Design Decision

> [!NOTE] Backup will be implemented workload-wide using platform-native solutions: Windows Backup and Restore for Worksations, Microsoft Azure Recovery Services agent for On-Prem and Azure Servers, and Microsoft 365 Backup for SharePoint, Exchange Online, and OneDrive. Retention will align with business criticality and business continuity requirements.

## Prerequisites

- **Permissions/Roles:** Intune Service Administrator permissions are required to configure the restore setting. [^1]

- **Dependencies:** Access to the Microsoft Intune admin center; devices running Windows 10 and later enrolled in Intune; ability to create a Windows Backup policy using the Settings Catalog under Enrollment. [^2]

[^1]: [Windows Backup for Organizations in Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/enrollment/windows-backup-restore#rbac-and-tenant-wide-targeting)

## Implementation Steps

### Workstations

1. Sign in to the Microsoft Intune admin center as an Intune service administrator.[^1]
2. Go to **Devices** > **Managed devices** > **Configuration**.
3. Create a new policy.
3.1. For **Platform**, select **Windows 10 and later**.
3.2. For **Profile type**, select **Settings Catalog**.
4. Under the **Sync your settings** category, find the **Enable Windows backup** setting. Select the setting to enable it.
5. Finish the remaining steps to create your policy. Then select **Save**.
6. Restore
   1. Sign in to the Microsoft Intune admin center as an Intune service administrator.
   2. Go to **Devices** > **Enrollment**.
   3. Select the **Windows** tab.
   4. Under **Enrollment options**, select **Windows Backup and Restore**.
   5. For **Show restore page**, select **On**.
   6. Tip: Before a user can restore a backup, you have to set up the backup settings in the settings catalog. To go to the settings catalog, select **Go to Settings Catalog to configure backup settings**.
   7. Select **Save**.
   The last modified date updates to account for recent changes. Return to **Windows Backup and Restore** anytime to view and edit the setting again.

### Microsoft 365

1. Create a OneDrive for Business protection policy using Microsoft Graph Backup Restore. When the policy is created, its state is set to inactive. See the Microsoft Graph Backup Restore documentation for details and syntax. [New-MgSolutionBackupRestoreOneDriveForBusinessProtectionPolicy] links are provided in the referenced material. [^2]
2. Use the policy to back up and restore content from OneDrive for Business as part of Microsoft 365 backups. Retention settings can be configured via the policy’s retention configuration parameters. [^2]
3. For reference and command details, see the Microsoft Graph PowerShell documentation:
   - New-MgSolutionBackupRestoreOneDriveForBusinessProtectionPolicy. [^2]
