## Summary

Configure **Memory integrity** by enabling **Hypervisor Enforced Code Integrity** through the **Settings Catalog** in **Intune**, or via the **VirtualizationBasedTechnology CSP**.[^1]

[^1]: [Enable memory integrity](https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity)

## Design Decision

Use **Intune** to (1) configure **Hypervisor Enforced Code Integrity** and (2) deploy **ScriptName.ps1** via **Intune/CSP**.

> [!NOTE]
> Memory integrity will be enabled through the **Hypervisor Enforced Code Integrity** setting via **Intune/CSP**.

## Prerequisites

- **Licensing:** Microsoft Intune Plan 1 licensing at minimum.[^1]

- **Dependencies:** Access to memory integrity configuration via the **Settings Catalog** in Intune; alternatively, access to the **Hypervisor Enforced Code Integrity** configuration via the CSP.[^1]

- **Dependencies - Hardware prerequisites for VBS and memory integrity:** 
  - 64-bit CPU with virtualization extensions (**Intel VT-x** and **AMD-v**)
  - Second Level Address Translation (**SLAT**)
  - IOMMU or SMMU for DMA protection
  - **TPM 2.0**
  - Firmware with SMM protection (**WMST**)
  - **UEFI memory reporting** with proper memory map attributes
  - **Secure Boot** enabled on devices leveraging VBS
  - For VBS in virtual machines, nested virtualization support or **Guest VSM** enabled.[^5]

## Implementation Steps

### Configure Policy using Settings Catalog

1. Create a new **Settings Catalog** policy.[^1]
2. In Intune, search for the setting under **Virtualization Based Technology** > **Hypervisor Enforced Code Integrity** and set it to **Enabled** to enforce **Memory integrity**.[^1]
3. Deploy the policy to target devices or users.[^1]
4. Restart the device after enabling memory integrity, if prompted by the policy application.[^2]

### Verify Memory Integrity Status

1. Open the System Information app (msinfo32). Look for the line "Virtualization-based security Services Running" and verify it reports **Hypervisor enforced Code Integrity**.[^3]
2. Alternatively, open Windows Security app and navigate to Settings > Update & Security > Windows Security > Device security > Core isolation details > **Memory integrity** to confirm memory integrity is enabled.[^3]
