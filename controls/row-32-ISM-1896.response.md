## Summary

Memory integrity provides kernel-level protection by enforcing code integrity through virtualization-based security. Enable memory integrity on devices with supported hardware using Intune/CSP by configuring the Virtualization Based Technology > Hypervisor Enforced Code Integrity setting in the Settings Catalog; Windows Security users can enable memory integrity via Device security > Core isolation details > Memory integrity. [^1]

[^1]: [https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity#how-to-turn-on-memory-integrity](https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity#how-to-turn-on-memory-integrity)

## Design Decision

> [!NOTE] Memory integrity will be enabled via the Virtualization Based Technology > Hypervisor Enforced Code Integrity setting in the Intune settings catalog (Intune/CSP).

## Prerequisites

* **Dependencies:** Hardware that supports Memory Integrity on Windows devices. [^1]

[^1]: [Enable virtualization-based protection of code integrity](https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity#how-to-turn-on-memory-integrity)

## Implementation Steps

### Enable memory integrity using Intune (Settings Catalog)

1. Use the settings catalog in Intune to configure Virtualization Based Technology > Hypervisor Enforced Code Integrity to enable memory integrity.[^1]

2. You can also use the HypervisorEnforcedCodeIntegrity node in the VirtualizationBasedTechnology CSP to enable memory integrity.[^1]

[^1]: [Enable virtualization-based protection of code integrity](https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity#how-to-turn-on-memory-integrity)
