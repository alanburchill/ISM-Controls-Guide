## Design Decision

Use **Microsoft Defender for Endpoint** to (1) configure **Onboard devices to Defender for Endpoint** and (2) deploy **DefenderOnboard.ps1** via **Defender onboarding flow**.

> [!NOTE]
> Deploying **DefenderOnboard.ps1** via Defender onboarding flow.

## Prerequisites

- **Dependencies:** Endpoints must be onboarded to Microsoft Defender for Endpoint.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Implementation Steps

### Onboard Devices to Defender for Endpoint

1. Create a new Windows Configuration Profile with type template **Microsoft Defender for Endpoint**.[^3]
2. Set **telemetry reporting frequency** to Enable.[^3]
3. Assign the profile to a group containing all applicable Windows devices.[^3]

### Review Vulnerabilities in Exposure management

1. Open the **Defender security portal**.[^3]
2. Navigate to **Exposure management** > **Vulnerabilities**.[^3]
3. Review the vulnerability data and remediation recommendations.[^3]
4. Optional: In **Vulnerability Management** > Inventories view software inventories and devices.[^3]

[^3]: [Essential Eight patch operating systems - Essential Eight - Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)
