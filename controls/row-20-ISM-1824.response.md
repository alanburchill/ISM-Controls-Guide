## Summary

Lock PDF security settings using Intune so users cannot change them[^1]. Implement via Intune device configuration profiles or security baselines to enforce consistent PDF security settings across endpoints[^5]. This approach aligns with ASD's Essential Eight user application hardening guidance for hardening PDF and related applications[^4].

## Design Decision

> [!NOTE] PDF security settings will be locked using Intune to prevent users from changing them.

## Prerequisites

* **Dependencies:** Microsoft Intune must be configured as the MDM authority to deploy device configuration profiles and enforce PDF security settings; Enroll devices through Intune and target configurations using Entra ID groups. [^5]
