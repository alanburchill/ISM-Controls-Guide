## Summary

Successful and unsuccessful MFA events are centrally logged and forwarded to Microsoft Log Analytics for centralized monitoring. Configure Entra ID Diagnostic Settings to stream logs to an Azure Event Hub for SIEM integration and Log Analytics. In Entra ID, navigate to Monitoring & health > Diagnostic settings, add or edit a diagnostic setting, name it, select log categories (AuditLogs, Sign-ins), enable Stream to an event hub, and choose the Event Hubs namespace. ## Design Decision

> [!NOTE] The 7-year retention policy will be applied to the Microsoft 365 Unified Audit log. The 10-Year Audit Log licences will be enabled with group-based assignment, and Entra ID Diagnostic Settings will be configured to stream all logs to a Log Analytics workspace.

## Prerequisites

* **Permissions/Roles:** Security Administrator access to create general diagnostic settings for the Microsoft Entra tenant; Attribute Log Administrator access to create diagnostic settings for custom security attribute logs. [^4]

* **Dependencies:** An Azure subscription; An Azure Event Hub that is already set up. [^4]
