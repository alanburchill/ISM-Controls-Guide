## Summary

Configure **Entra ID Diagnostic Settings** to save all logs to a **Log Analytics workspace**.[^1] Not provided in source documentation.

[^1]: [Access activity logs in Microsoft Entra ID - Microsoft Entra ID - Microsoft Learn](https://learn.microsoft.com/en-us/entra/identity/monitoring-health/howto-access-activity-logs)

## Design Decision

Use **Microsoft Entra ID** to (1) configure **7 year retention log policy** for the Microsoft 365 Unified Audit log and (2) enable **10-Year Audit Log licences** via **group-based assignment**, and to configure **Microsoft Entra ID Diagnostic Settings** to save all logs to a **Log Analytics workspace**.

> [!NOTE]
> Deploying **Configure-EntraAudit.ps1** will apply the retention policy, licences and diagnostic settings.

## Prerequisites

* **Permissions/Roles:** At least Security Administrator to access Entra ID diagnostic settings and configurations; at least a Reports Reader to view and download logs. [^1]
* **Dependencies:** Create a Log Analytics workspace; configure Entra ID Diagnostic Settings to stream logs to the workspace. [^1]

[^1]: [Access activity logs in Microsoft Entra ID - Microsoft Entra ID - Microsoft Learn](https://learn.microsoft.com/en-us/entra/identity/monitoring-health/howto-access-activity-logs)

## Implementation Steps

### Configure Diagnostic Settings to Save Logs to a Log Analytics Workspace

1. Sign in to the Microsoft Entra admin center as at least a **Security Administrator**.^1
2. Create a **Log Analytics workspace**.^1
3. Browse to Entra ID > Monitoring & health > **Diagnostic settings**.^1
4. In **Diagnostic settings**, choose the logs you want to stream and enable the **Send to Log Analytics workspace** option for the workspace. Include the following logs: **Audit logs**, **Sign-in logs**, and **Provisioning logs**.^1^[^4]
5. Review the data retention policies for the selected logs.^1

| Logs to stream | Included in stream |
| -------------- | ------------------ |
| Audit logs     | Yes                |
| Sign-in logs   | Yes                |
| Provisioning logs | Yes             |
