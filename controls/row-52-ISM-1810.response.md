## Summary

Backups of data, applications, and settings must be synchronised to enable restoration to a common point in time[^7]. Implement this using Azure-based backup with point-in-time restore capabilities to create restore points for Cloud PCs and data[^4][^9]. Administrators can configure point-in-time restore settings in the Microsoft Intune admin center, including cadence and scope, and execute bulk, manual, or single-Cloud-PC restores as needed[^1][^2][^3][^10].

## Design Decision

> [!NOTE] Use Azure Backup to take application-consistent snapshots for synchronised restore points.

## Prerequisites

* **Permissions/Roles:** Intune Service Administrator permissions are required to configure Windows Backup and Restore in Intune. [^1]
* **Dependencies:** Microsoft Intune admin center is required to perform restore point creation and backup operations. [^2]

## Implementation Steps

### Azure Backup-based application-consistent snapshots for synchronised restore points

1. Sign in to the Microsoft Intune admin center as an Intune service administrator. [^1]

2. Configure Windows backup settings in a new policy:
   2.1. Create a policy: Platform = Windows 10 and later; Profile type = Settings Catalog.  
   2.2. In Sync your settings, enable Windows backup.  
   2.3. Save the policy. [^1]

3. Configure restore permissions for end users:
   3.1. On the Add user setting page, type a Name.  
   3.2. If local admin rights are desired, enable Local admin.  
   3.3. If end users should restore their Cloud PCs, enable Allow user to initiate restore service.  
   3.4. For Frequency of restore-point service, select an interval (limit of 10 restore points).  
   3.5. Click Next. [^2]

4. Assign the user setting to groups:
   4.1. On the Assignments page, select the groups to receive this setting.  
   4.2. Click Next and then Finish. [^2]

5. Enable Windows Backup and Restore enrollment for devices:
   5.1. Sign in to the Intune admin center as an Intune service administrator.  
   5.2. Go to Devices > Enrollment.  
   5.3. On the Windows tab, under Enrollment options, select Windows Backup and Restore.  
   5.4. For Show restore page, set On.  
   5.5. Save. [^1]

6. Create and manage restore points for Cloud PCs:
   6.1. For on-demand restore points, use Bulk Device Actions to Create restore points for Windows Cloud PCs (bulk restore).  
   6.2. On the Basics page, configure: OS = Windows; Device type = Cloud PCs; Device action = Restore.  
   6.3. Specify date/time and choose the restore point time range (Before, After, or Whichever is closest).  
   6.4. If desired, enable Skip unhealthy snapshots to use only healthy points.  
   6.5. Click Next, select devices, and then Create. [^3]

7. Create manual restore points in bulk (optional):
   7.1. Sign in to the Intune admin center > Devices > All devices > Bulk Device Actions.  
   7.2. Basics: OS = Windows; Device type = Cloud PCs; Device action = Create restore points.  
   7.3. (Optional) If sharing to storage, choose Create new restore point for share and specify Subscription, Storage account, and Access tier.  
   7.4. Click Next.  
   7.5. On the Devices page, choose Select devices to include.  
   7.6. Select devices and click Next.  
   7.7. Review + create → Create.  
   7.8. Newly created restore points may take time to appear. If a Cloud PC already has a restore point, that point may be overwritten. [^4]

8. Share restore points to an Azure Storage Account (optional):
   8.1. Sign in to Intune admin center > Devices > All devices > Bulk Device Actions.  
   8.2. Basics: OS = Windows; Device action = Share Cloud PC restore point to storage.  
   8.3. Specify date/time and restore point time range (Before, After, or Closest).  
   8.4. Select Subscription, Storage account, and Access tier.  
   8.5. On the Devices page, select Cloud PCs to share points for.  
   8.6. Review + create → Create.  
   8.7. Each restore point creates a folder in the storage account named after the Cloud PC, containing a VHD copy. [^5]

9. Restore a single Cloud PC to a previous state (selected restore point):
   9.1. Sign in to Intune admin center > Devices > Windows 365 > All Cloud PCs, choose a Cloud PC.  
   9.2. Click Restore and, under Select restore point, choose the desired point.  
   9.3. Confirm the Restore action.  
   9.4. The Cloud PC status updates to Restoring on the All Cloud PCs page and on the end-user portal until complete. [^6]

10. Additional restore capabilities (optional):
    10.1. You can bulk restore Cloud PCs using the bulk restore flow described in step 6.  
    10.2. You can bulk share restore points as described in step 8.  
    10.3. You can create on-demand manual restore points in bulk as described in step 7. [^3][^4][^5]

11. Backup immutability and geographic redundancy (recommended controls):
    11.1. Enable immutable vaults and configure retention and multi-user authorization to protect backup data from deletion or tampering.  
    11.2. Enable cross-region restore (GRS) and zone-redundant storage (ZRS) for Recovery Services vaults.  
    11.3. Periodically test cross-region recovery and document failover procedures. [^7]
