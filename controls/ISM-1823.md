## Summary

This ISM control ensures that **Office productivity suite security settings** cannot be changed by users, reducing the risk of insecure configurations. Deploying **Intune Office hardening policies** enforces these settings and prevents user-initiated modifications, strengthening the organization's security posture.[^1]

## Design Decision

> [!NOTE]

## Prerequisites

- **Permissions/Roles:**
  - A user account with the built-in **Policy and Profile Manager** role is required to create and manage policies in the **Microsoft Intune** admin center. [^5]

- **Dependencies:**
  - Devices must be enrolled in **Microsoft Intune** and joined to **Entra ID** (Azure AD) or hybrid Azure AD joined to apply Intune policies. [^1]
  - Policies are deployed via the **Intune Settings Catalog** as the configuration mechanism for Office hardening. [^5]

## Implementation Steps

### Intune Office Hardening Policy Deployment via Settings Catalog

1. Sign in to the Microsoft Intune admin center and create a new policy: Devices > Manage devices > Configuration > Create > New policy. Platform: Windows 10 and later. Profile type: Settings catalog.[^5]

2. In Basics, provide a name and a description for the policy. This helps identify the policy later.[^5]

3. In Configuration settings, select Add settings. In the settings picker, choose a category that contains Office hardening controls and select the desired Office security settings to enforce.[^5]

4. If you do not want to configure a setting, leave it not configured by selecting the minus sign (-). After configuring the desired settings, close the picker. The defaults shown reflect OS defaults.[^5]

5. In Scope tags (optional), assign a tag to filter the profile to specific IT groups. Then in Assignments, select the users or groups that will receive the profile.[^5]

6. In Review + create, review your settings. When you select Create, the policy is saved and the profile is assigned. The next time the device checks for configuration updates, the settings are applied.[^5]

7. Enforcement note: Office security settings deployed via Intune are enforced and cannot be changed by standard users. This behavior is part of the Intune-based hardening approach.[^1]

### Block Microsoft Office macros with Intune policy

1. Create a group that contains users who are able to run Office macros if they're signed by a Trusted Publisher. This group is referred to as Allow macro execution - Trusted Publisher. [^4]

2. Save the policy to your local device with the name All Macros Disabled policy. [^4]

3. Open the Microsoft Intune console. Navigate to Devices > Windows > Configuration profiles > Import Policy. [^4]

4. Import the saved policy, name the policy appropriately, and click Save. [^4]

5. Assign the All Macros Disabled policy to All Office Users by default. Exclude the Allow macro execution - Trusted Publisher group from this policy. [^4]

6. Outcome: Microsoft Office macros are blocked for users that do not have a demonstrated business requirement. The policy targets All Office users by default, with exceptions for the Trusted Publisher group. [^4]
