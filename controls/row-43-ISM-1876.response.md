## Summary

Push critical OS patches within 48 hours using Intune expedited updates (Windows Autopatch). Onboard endpoints into Microsoft Defender for Endpoint and enable Expedite telemetry reporting to support vulnerability identification. Use Defender vulnerability management to identify vulnerabilities and deploy patches within 48 hours via Intune deployment methods.

## Design Decision

> [!NOTE] Critical OS patches will be pushed within 48 hours using Intune expedited updates via Windows Autopatch.

## Prerequisites

No specific prerequisites identified in source documentation.

## Implementation Steps

### Onboard endpoints to Microsoft Defender for Endpoint and enable expedited telemetry

1. Create a new Windows Configuration Profile with a type of Template > Microsoft Defender for Endpoint (desktop devices running Windows 10 or later).[^1]
2. Set Expedite telemetry reporting frequency to Enable.[^1]
3. Assign the profile to a group containing all applicable Windows devices.[^1]

### Patch OS within 48 hours using Defender vulnerability management and Intune deployment

1. Use Microsoft Defender vulnerability method to identify vulnerabilities.[^2]
2. Intune deployment method is used to deploy the patches within 48 hours of release.[^2]
