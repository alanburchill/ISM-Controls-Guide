## Summary

Push **critical OS patches** within 48 hours using **Intune expedited updates** enabled by **Windows Autopatch**.[^1]

[^1]: [ASD Blueprint: Windows update and patching](https://blueprint.asd.gov.au/design/endpoints/windows/configuration/windows-update-and-patching/)

## Design Decision

Use **Windows Autopatch** to (1) configure **Expedited OS patching** and (2) deploy **ScriptName.ps1** via Intune deployment.

> [!NOTE]
> Deploying **ScriptName.ps1** also disables **Other Feature**.

## Prerequisites

### Dependencies
1. Run the Windows Autopatch readiness assessment to verify settings in **Intune** and **Microsoft Entra ID** for enrollment.[^1]
2. Prepare admin contacts for each focus area and configure them in the Windows Autopatch Admin contacts section in **Intune**.[^1]
3. Review and fulfill Windows Autopatch device registration prerequisites before registering devices. Identify devices to be managed and add them into the Windows Autopatch Device Registration **Microsoft Entra** group.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight - Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Implementation Steps

### Enroll Devices in **Windows Autopatch** for Expedited OS Patch Deployment

1. As a Global Administrator, open **Intune** and navigate to Windows Autopatch > Tenant enrollment. Run the Readiness assessment to verify ring configuration and admin requirements. Address any issues before proceeding.[^2]

2. In **Intune**, go to Tenant administration > Windows Autopatch > Admin contacts. Add admin contacts for each area of focus (Devices, Device health, Updates, Windows quality updates, Microsoft 365 Apps updates, Microsoft Edge updates, Microsoft Teams updates) and save.[^2]

3. Review prerequisites for device registration and identify devices to enroll. Add devices to the Windows Autopatch Device Registration group. Windows Autopatch will calculate deployment rings, assign devices to rings, and begin update policy application. Monitor device status through the Autopatch dashboard.[^2]

4. If expedited patching is required, configure Autopatch groups to bring deadlines to within 48 hours for critical patches, as allowed by Autopatch groups.[^2]

### Monitor Patch Deployment and Verify Compliance via **Intune** and Autopatch Dashboard

1. Sign into **Intune** and navigate to Reports > Windows Autopatch > Windows Quality Updates to view the current update status for enrolled devices.[^2]

2. Open the All Devices Report to review details such as device name, deployment ring, and status, and verify that critical patches are deployed within the 48-hour window where applicable.[^2]

3. Use the Autopatch dashboard to monitor ongoing deployments and generate reports for audit or compliance purposes (e.g., 90-day historical reports). The dashboard provides status updates for devices enrolled in Windows Autopatch.[^2]

> [!NOTE]
> Windows Autopatch groups enable expedited patching for critical vulnerabilities when required.[^2]
