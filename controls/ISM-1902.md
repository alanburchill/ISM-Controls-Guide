# Patches, updates or other vendor mitigations for vulnerabilities in operating systems of workstations, non-internet-facing servers and non-internet-facing network devices are applied within one month of release when vulnerabilities are assessed as non-critical by vendors and no working exploits exist.

## Summary

Configure **Monthly patch cadence for non-critical OS updates** via **Intune Windows AutoPatch** and deploy **ScriptName.ps1** using **Windows Autopatch deployment**.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Design Decision

Use **Windows Autopatch** to (1) configure **Monthly patch cadence for non-critical OS updates via Intune Windows AutoPatch** and (2) deploy updates via **Intune**.

> [!NOTE]
> Deploying Windows Autopatch configuration enforces the monthly cadence for non-critical updates.

## Prerequisites

- **Permissions/Roles:** Global Administrator privileges are required to access Intune and enroll in Windows Autopatch; minimum administrator requirements and unlicensed administrators must be accounted for.[^1]

- **Dependencies:** The Windows Autopatch enrollment requires configured Microsoft Intune and Microsoft Entra ID; the readiness assessment checks these settings to ensure readiness for enrollment.[^1]

- **Dependencies:** Admin contacts must be configured for each area of focus and available for future communications.[^1]

- **Dependencies:** Device registration prerequisites must be reviewed prior to registering devices with Windows Autopatch; IT admin reviews Windows Autopatch device registration prerequisites before registration.[^1]

- **Dependencies:** Any device with a Microsoft Entra device ID can be registered; Windows 365 Cloud PCs are exempt from enrollment.[^1]

[^1]: [Essential Eight patch operating systems - Essential Eight | Microsoft Learn](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)

## Implementation Steps

### Enable Windows Autopatch Enrollment in Intune

1. Run the **Readiness assessment** tool to confirm Intune and Entra ID readiness for **Windows Autopatch** enrollment. [^1]
2. As a Global Administrator, open the Intune console and navigate to **Tenant administration** > **Windows Autopatch** > **Tenant enrollment** to enable enrollment. [^1]
3. In Intune, add admin contacts for each area of focus via the **Admin contacts** page to support future updates and investigations. [^1]
4. Prepare devices and enroll them into **Windows Autopatch** by adding them to the appropriate device groups. The service will perform device readiness checks, calculate deployment ring distribution, assign devices to a deployment ring, and mark devices as active for management. [^1]
5. Monitor enrollment and update status using the **Autopatch dashboard** and reporting. To view the current update status for enrolled devices, sign in to **Intune** and navigate to **Reports** > **Windows Autopatch** > **Windows Quality Updates**. [^1]

### Maintain monthly cadence for non-critical OS updates via Intune Windows AutoPatch

1. After enrollment, assign devices to a deployment ring in **Windows Autopatch** to manage the update cadence for non-critical OS updates. [^1]
2. Ensure non-critical OS updates are installed within approximately two weeks on enrolled devices. [^1]
3. Use the **All Devices Report** and the **Windows Quality Updates** view in **Autopatch** to monitor per-device update status and ring assignments. [^1]
4. If critical vulnerabilities arise, shorten update deadlines using **Autopatch** groups to within 48 hours if necessary. [^1]

[^1]: [Essential Eight patch operating systems](https://learn.microsoft.com/en-us/compliance/anz/e8-patch-os)
