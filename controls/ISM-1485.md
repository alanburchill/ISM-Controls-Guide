# Web browsers do not process web advertisements from the internet.

## Summary

Configure **Ads setting for sites with intrusive ads** via **Intune security baseline** and deploy **EdgeAdsPolicy.ps1** using **Intune security baseline**.[^1]

[^1]: [Technical example: User application hardening](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/small-business-cyber-security/small-business-cloud-security-guide/technical-example-user-application-hardening)

## Design Decision

Use **Microsoft Edge** to (1) configure **Ads setting for sites with intrusive ads** and (2) deploy **UserApplicationHardening-RemoveFeatures.ps1** via **Intune security baseline**.

> [!NOTE]
> Deploying **UserApplicationHardening-RemoveFeatures.ps1** also disables legacy features such as **.NET Framework 3.5**.

## Prerequisites

### Permissions/Roles
- Enroll organisation devices into Microsoft Intune and enable security defaults. [^1]
- Have access to the Microsoft Intune admin center to create and deploy a Settings Catalog policy. [^1]

### Dependencies
- Target platform: Windows 10 and later. [^1]
- Ability to create and deploy a Settings Catalog policy via Microsoft Intune. [^1]

[^1]: [Technical example: User application hardening](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/small-business-cyber-security/small-business-cloud-security-guide/technical-example-user-application-hardening)

## Implementation Steps

### Enable Edge Ads blocking using Settings Catalog

1. Log into the Intune admin center.[^1]
2. Create a new **Settings Catalog** policy.[^1]
3. On the Create profile panel, select the platform **Windows 10 and later**, select the profile type **Settings catalog**, then choose **Create**.[^1]
4. In the Settings picker, select **Microsoft Edge** then **Ads setting for sites with intrusive ads**. Under the Microsoft Edge heading, select **Enabled** and ensure **Block ads on sites with intrusive ads**. (Default value is also toggled on.)[^1]
5. Deploy the policy to target devices or users.[^1]

| Setting | Value |
| ------- | ----- |
| Ads setting for sites with intrusive ads (Microsoft Edge) | Enabled |

> [!NOTE]
> This policy blocks intrusive ads in Microsoft Edge as part of Edge hardening efforts.[^1]

### Enable Edge intrusive ads blocking via Microsoft Edge Security Baseline

1. Open the Microsoft Intune admin center.[^3]
2. Navigate to **Endpoint Security** > **Security Baselines**.[^3]
3. Select **Microsoft Edge Baseline** and create a profile.[^3]
4. Review the configuration and assign the baseline to a group.[^3]

> This method uses the Microsoft Edge Security Baseline to apply edge hardening configurations, including policies aligned with Edge security guidance.[^3]
