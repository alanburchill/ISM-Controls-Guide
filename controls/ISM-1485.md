## Summary

Enable Edge policy to block intrusive ads using the Intune security baseline by configuring **Ads setting for sites with intrusive ads** to Enabled, reducing exposure to potentially malicious advertising and supporting browser hardening. [^1]

### Justification

Not provided in source documentation.

[^1]: Essential Eight user application hardening (https://learn.microsoft.com/en-us/compliance/anz/e8-app-harden)

## Design Decision

> [!NOTE]
> The **Ads setting for sites with intrusive ads** policy will be enabled using the **Intune security baseline** to block intrusive ads in **Microsoft Edge**. This will be aligned with the control's intent to prevent web advertisements from being processed by browsers.

## Prerequisites

### Licensing
- **Microsoft Intune Plan 1** is required for target devices when implementing via **Intune security baseline**. [^2]

### Permissions/Roles
- Access to the **Intune admin center** with rights to create and deploy policies (e.g., **Web Protection** policy). [^2]
- Devices must be enrolled in **Entra ID** and managed by **Intune** for policy deployment. [^2]

### Dependencies
- **ASD Blueprint Edge hardening** baseline deployment to enable Edge policy for intrusive ads blocking. [^4]
- The Edge baseline includes blocking intrusive ads via the relevant policy, as configured in the **Edge Security Baseline**. [^1]
