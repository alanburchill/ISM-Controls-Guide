## Summary

Enforce browser security settings via Intune to prevent users from modifying them.[^1] Use configuration policies to lock Edge and Internet Explorer settings, including DoNotAllowUsersToChangePolicies for Internet Explorer to stop changes to security zones.[^3][^2] Device Configuration Profiles provide the mechanism to deploy and enforce these browser settings across endpoints.[^4]

## Design Decision

> [!NOTE] Enforce browser security settings via Intune to prevent users from modifying them.

## Prerequisites

* **Licensing:** Microsoft Intune Plan 1 licensing at minimum for configuring devices via Intune configuration policies and Edge management service. [^1]

## Implementation Steps

### Enforce browser security settings via Intune

1. Save the ACSC Microsoft Edge Hardening Guidelines policy JSON to your local device. [^1]

2. Open the Microsoft Intune console. [^1]

3. Import the policy: Devices > Windows > Configuration profiles > Create > Import Policy. [^1]

4. Name the policy, browse for the policy file under Policy file, navigate to the saved policy from step 1, and click Save. [^1]

5. Deploy the policy to Entra ID groups. Configuration policies can be assigned to multiple groups; policies merge when a user is in multiple policies, and the highest-priority policy applies for cloud policies. Intune policies do not have priority, and conflicting settings are not automatically resolved. [^3]

6. If using the Edge management service, create a configuration policy and assign it to target groups. Follow the guidance for “Get started with configuration policies” and assign the policy to groups. [^3]

7. Refer to Device Configuration Profiles for deployment scope and coverage. Device Configuration Profiles provide the ability to control settings and features on endpoints and can be deployed to specific users or devices in Entra ID groups. [^4]
