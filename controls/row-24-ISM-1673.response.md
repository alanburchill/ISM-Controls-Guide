## Summary

Enable the Attack Surface Reduction (ASR) policy in Intune to block Win32 API calls from Office macros. Configure the ASR rule to Block (Win32 API calls from Office macros) under Endpoint Security > ASR (MDM) to enforce macro hardening.[^1][^4] This aligns with Defender for Endpoint baseline guidance and ASD Office macro hardening recommendations.[^2][^3]

## Implementation Steps

### Enable ASR rule to block Win32 API calls from Office macros via Intune

1. In the Intune admin center, create or edit an Attack Surface Reduction (ASR) policy (MDM) for endpoint security. [^1]

2. In the policy, enable the setting Block Win32 API calls from Office macros by selecting Block. This corresponds to the ASR option to block Win32 API calls from Office macros. [^1]

3. Cross-reference Defender for Endpoint baseline coverage to ensure alignment with the baseline guidance for April 2020 — version 4, which includes Block Win32 API calls from Office macros. [^2]

4. Refer to Defender Exploit Guard mappings to confirm that blocking Win32 imports from Office macro code is enforced as part of the macro hardening guidance. [^3]
