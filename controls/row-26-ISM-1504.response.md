# Multi-factor authentication is used to authenticate users to their organisation’s online services that process, store or communicate their organisation’s sensitive data. (ISM-1504)

## Summary

If the only service uses Entra ID SSO authentication, create a Conditional Access policy that requires multifactor authentication for the Azure VPN Client app.^[^1][^2] In the Entra ID admin center, sign in as a Conditional Access Administrator, navigate to Protection > Security Center > Conditional Access, create a new policy (e.g., VPN Policy), include the VPN users and the Azure VPN Client app, configure Grant to require MFA, and enable the policy.^[^2][^3]

[^1]: [Option 2 - Conditional Access](https://learn.microsoft.com/en-us/azure/vpn-gateway/openvpn-azure-ad-mfa#option-2---conditional-access)
[^2]: [Create a Conditional Access policy](https://learn.microsoft.com/en-us/entra/external-id/customers/how-to-multifactor-authentication-customers#create-a-conditional-access-policy)
[^3]: [Policy configuration](https://learn.microsoft.com/en-us/partner-center/security/mfa-for-users#policy-configuration#Policy-configuration)

## Design Decision

> [!NOTE] A Conditional Access policy will be created in the Entra ID Portal to require multifactor authentication for the Entra ID SSO app used by the sole service.

## Prerequisites

* **Permissions/Roles:** 
  1. Conditional Access Administrator is required to sign in to the Microsoft Entra admin center and manage Conditional Access policies. [^1]
  2. Security Administrator is required to configure MFA policies in the Microsoft Entra admin center. [^2]

[^1]: [Option 2 - Conditional Access](https://learn.microsoft.com/en-us/azure/vpn-gateway/openvpn-azure-ad-mfa#option-2---conditional-access)
[^2]: [Policy configuration](https://learn.microsoft.com/en-us/partner-center/security/mfa-for-users#policy-configuration#Policy-configuration)

## Implementation Steps

### Create Conditional Access policy to require MFA for Entra ID SSO VPN app

1. Sign in to the Microsoft Entra admin center as at least a Conditional Access Administrator.[^1]

2. Browse to Protection > Security Center > Conditional Access, select + New policy, and then select Create new policy.[^1]

3. On the New pane, enter a name for the policy, such as VPN Policy.[^1]

4. Complete the following fields:
   - What does this policy apply to? Users and groups
   - Assignments: Specific users included
   - Include: Select users and groups. Select at least one user or group
   [1]

5. On the Select page, browse for and select the Microsoft Entra user or group to which you want this policy to apply. For example, VPN Users, then choose Select.[^1]

6. Next, configure conditions for multifactor authentication. In the following steps, you configure the Azure VPN Client app to require multifactor authentication when a user signs in. For more information, see Configure the conditions for multifactor authentication.[^1]

6.1. Select the current value under Cloud apps or actions, and then under Select what this policy applies to, verify that Cloud apps is selected.[^1]

6.2. Under Include, choose Select resources. Since no apps are yet selected, the list of apps opens automatically.[^1]

6.3. In the Select pane, select the Azure VPN Client app, then choose Select.[^1]

7. Next, configure the access controls to require multifactor authentication during a sign-in event.

7.1. Under Access controls, select Grant, and then select Grant access.[^1]

7.2. Select Require multifactor authentication.[^1]

7.3. For multiple controls, select Require all the selected controls.[^1]

8. Now, activate the policy.

8.1. Under Enable policy, select On.[^1]

8.2. To apply the Conditional Access policy, select Create.[^1]

[^1]: [Option 2 - Conditional Access](https://learn.microsoft.com/en-us/azure/vpn-gateway/openvpn-azure-ad-mfa#option-2---conditional-access)
