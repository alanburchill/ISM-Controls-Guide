## Summary

Configure **Conditional Access policy** via **Entra ID Portal** to require **multifactor authentication** for the targeted Entra ID SSO app. Deploy the policy to enforce MFA for the app's users.[^1]

[^1]: [Create a Conditional Access policy - Microsoft Entra ID - Microsoft Learn](https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-all-users-mfa-strength)

## Design Decision

Use **Microsoft Entra ID** to (1) configure **Conditional Access policy requiring multifactor authentication targeted to the Entra ID SSO app** and (2) deploy **ScriptName.ps1** via **Entra ID Portal**.

> [!NOTE]
> The design choice ensures MFA is enforced for the Entra ID SSO app through a Conditional Access policy.

## Prerequisites

- **Permissions/Roles:** Sign in to the Microsoft Entra admin center with at least the **Conditional Access Administrator** role to configure Conditional Access policies.[^1]

[^1]: [Require MFA for all users with Conditional Access - Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-all-users-mfa-strength)

## Implementation Steps

### Create Conditional Access policy for Entra ID SSO app

1. Sign in to the Microsoft Entra admin center as an administrator with **Conditional Access** privileges. [^1]
2. Navigate to Entra ID > Conditional Access > Policies. [^1]
3. Select New policy and provide a meaningful name for the policy. [^1]
4. Under Assignments, include the targeted users or groups. Under Cloud apps or actions, include the Entra ID SSO app that the service uses. [^1]
5. Under Access controls > **Grant**, select **Require authentication strength** and choose the built-in MFA authentication strength from the list. [^1]
6. Under Enable policy, set to On. [^1]
7. Click Create to finalize and enable the policy. [^1]

> [!NOTE]
> This implementation aligns with guidance to create a Conditional Access policy that enforces MFA for a specific app using Entra ID Portal. [^1]

[^1]: [Create a Conditional Access policy](https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-all-users-mfa-strength)
