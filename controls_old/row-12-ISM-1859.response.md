## Summary

Apply ACSC office-hardening policies to Microsoft Office via Intune configuration profiles to harden Office productivity suites as required by ACSC guidance. Hardening aligns with ASD Blueprint guidance, with the most restrictive controls taking precedence when conflicts occur. Example controls include blocking macros from the internet, enabling antivirus scanning of Microsoft macros, and restricting macro execution to digitally signed publishers, all configured through Intune ACSC Office Hardening policies.

## Implementation Steps

### ACSC Office Hardening via Intune

1. Deploy the ACSC Office Hardening policy for Microsoft 365 Apps for Enterprise to All Office Users (created in Stage 1). Audit mode should be used during initial rollout to test compatibility before enforcement. [^1]

2. Configure Attack Surface Reduction (ASR) and related macro hardening settings as part of the policy, in audit mode for testing. [^1]

3. Harden Office macros per ASD blueprint guidance:
   - Only allow Microsoft macros that are digitally signed by a trusted publisher to execute. [^3]
   - Disable all macros downloaded from the Internet. [^3]
   - Enable antivirus scanning of Microsoft macros. [^3]
   - Prevent users from changing macro settings. [^3]

4. Configure Defender for Endpoint to centrally store EDR logs and forward them to Log Analytics. [^3]

5. Apply additional macro and Office hardening controls:
   - Block macros from running in Office files from the Internet: Enabled. [^1]
   - Disable the Trust Bar notification for unsigned publishers: Enabled. [^1]
   - Block Win32 API calls from Office macros: ASR rule with ID 92E97FA1-2EDF-4476-BDD6-9DD0B4DDDC7B. [^1]

6. Assign the policy to All Office Users (as defined in Stage 1) and monitor for issues. [^1]

7. Reference remote scripts for implementation and verification:
   - Use the OfficeMacroHardening-PreventActivationofOLE.ps1 script to meet OLE-related hardening controls. [^4]
   - Use the UserApplicationHardening-RemoveFeatures.ps1 script to disable legacy features and strengthen application hardening. [^5]
