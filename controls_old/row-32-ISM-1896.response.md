## Summary

Memory integrity is a virtualization-based security feature that hardens Windows by enforcing kernel code integrity.[^1] Turn on Memory Integrity using Intune security baseline to apply enterprise-wide settings.[^2] Compatibility issues may arise with certain hardware or drivers; validate enablement using the Win32_DeviceGuard WMI class or msinfo32.[^1]

## Design Decision

> [!NOTE] Enable Memory Integrity via the Intune security baseline on Windows devices with supporting hardware. This enforces kernel-mode memory protection using virtualization-based security.
