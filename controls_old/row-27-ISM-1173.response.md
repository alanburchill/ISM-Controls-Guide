## Summary

Multi-factor authentication (MFA) strengthens authentication for privileged accounts by requiring an additional verification factor.[^5] Create a Conditional Access policy that requires MFA for all privileged accounts to enforce this baseline security.[^1] This approach aligns with best practices for privileged access management and identity security, which advocate MFA for administrators and the use of Just-In-Time access where possible.[^4][^3]

## Design Decision

> [!NOTE] Implement a Conditional Access policy requiring MFA for all privileged accounts to enforce strong authentication before accessing privileged resources.

## Prerequisites

* **Licensing:** Microsoft 365 Enterprise E5 or an equivalent product. [^1]
* **Permissions/Roles:** Administrative access to configure Conditional Access policies and enforce MFA for administrators. [^1]
* **Dependencies:** Microsoft Entra ID with Conditional Access capabilities enabled and MFA configuration for administrators. [^1]

## Implementation Steps

### Conditional Access policy requiring MFA for privileged accounts

1. Create privileged admin groups. Create groups such as:
   - Secure Workstation Admins
   - Emergency BreakGlass
   and include the appropriate users in each group. [^1]

2. Create a Conditional Access policy that requires MFA for administrators when signing in to cloud applications. Apply the policy to the Secure Workstation Admins group and require MFA as the condition for access. [^1]

3. Enforce device requirements. Configure the policy so administrators sign in from devices that can present a specific device attribute value and are compliant. The device must be marked compliant by Microsoft Endpoint Manager and Microsoft Defender for Endpoint. [^1]

4. Exclude emergency access accounts from the policy. Add the Emergency BreakGlass group to bypass or exception rules within the policy to ensure emergency accounts can access in extreme scenarios. [^1]

5. Block non-PAW device access to cloud management interfaces. The policy should block privileged users from connecting to cloud portals, management interfaces, and PowerShell from devices that are not Privileged Access Workstations (PAWs) or do not meet the required device criteria. [^1]

6. Consider blocking legacy authentication protocols. Evaluate and implement blocks for legacy authentication in conjunction with the CA policy as appropriate for the environment. [^1]
