# A vulnerability scanner is used at least fortnightly to identify missing patches or updates for vulnerabilities in operating systems of workstations, non-internet-facing servers and non-internet-facing network devices. (ISM-1702)

## Summary

Onboard devices to Microsoft Defender for Endpoint and enable Defender Vulnerability Management to continuously monitor vulnerabilities across devices.[^1][^4]

Use the Defender portal, Exposure management > Vulnerabilities, to view and remediate vulnerabilities across the environment.[^3][^4]

Remediation tasks can be created and tracked in Intune from security recommendations.[^4]

## Design Decision

> [!NOTE] Onboard devices to Defender for Endpoint and enable Defender Vulnerability Management. Use the Defender portal's Exposure management > Vulnerabilities report to view unmitigated vulnerabilities.

## Prerequisites

* **Licensing:** Licensing is required for Defender Vulnerability Management. It can be provided as a standalone offering (DVM) or as part of Microsoft Defender for Endpoint Plan 2 or Microsoft 365 E5; full capabilities are available as an add-on. [^4]
* **Permissions/Roles:** Access to the Defender portal requires the user to be in the Security Reader role. [^4]
* **Dependencies:** Devices must be onboarded to Microsoft Defender for Endpoint; Defender Vulnerability Management features must be enabled for onboarded devices; Access to the Defender portal with the required role is necessary; If devices are not onboarded, Defender for Endpoint must run in block mode. [^4]

## Implementation Steps

### Onboard devices to Defender for Endpoint and enable vulnerability management

1. If devices are already onboarded to Defender for Endpoint, enable Defender Vulnerability Management (DVM) features in the Microsoft Defender portal. Not provided in source documentation. [^1]

2. If devices are not onboarded to Defender for Endpoint, ensure Defender for Endpoint is installed on those devices and running in block mode (passive mode) to enable vulnerability management. Not provided in source documentation. [^1]

3. Onboard devices using supported methods such as group policy, Microsoft Endpoint Manager (Intune), or local scripts. Detailed guidance is documented in the onboarding guidance for Defender for Endpoint capabilities. Not provided in source documentation. [^1]

4. After onboarding, Defender Vulnerability Management continuously monitors and detects risk across an organization’s devices. Not provided in source documentation. [^1]

### Access vulnerability report in Microsoft Defender portal

1. Open the Microsoft Defender portal.

2. Note: The Vulnerability Management experience is now located under Exposure management. Not provided in source documentation. [^3]

3. Use the Vulnerability Management dashboard to view vulnerability exposure across assets, including consolidated inventories of software, vulnerabilities, and exposed devices. Not provided in source documentation. [^4]

4. To view details for a specific software entry, navigate to the software entry to see CVEs, devices affected, and related information. Not provided in source documentation. [^4]
