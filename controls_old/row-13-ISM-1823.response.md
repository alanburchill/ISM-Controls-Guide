## Summary

Deploy Intune Office hardening policies to ensure Office security settings cannot be changed by users. Intune's Microsoft 365 Apps for Enterprise security baseline provides preconfigured settings (including macro and Trust Center controls) applied as a customizable template to enforce the required Office hardening[^1][^2]. When deployed, these policies enforce the contained settings and prevent standard users from altering them[^1].

## Design Decision

> [!NOTE] Deploy Intune Office hardening policies to prevent users from changing Office security settings and to enforce a locked-down Office baseline. This ensures Office configurations remain consistent with the control requirement that security settings cannot be changed by users.

## Implementation Steps

### Deploy Microsoft 365 Apps security baseline (Office hardening)

1. In the Intune admin center, navigate to Endpoint Security > Security Baselines.  
2. Create or select the Microsoft 365 Apps for Enterprise security baseline, ensuring you use the version that includes Office hardening settings (version referenced as 2306 in the baseline guidance) and is deployed to the target devices. [^2]  
3. Ensure the following Office security settings are enabled within the baseline:
   - Block macros from running in Office files from the Internet (User). Baseline default: Enabled. [^2]  
4. Assign the baseline to the appropriate device groups. [^3]  
5. Monitor deployment status and verify the baseline is applied to devices. The baseline enforcement is designed to prevent standard users from changing the configured Office security settings. [^1]

### Optional: Supplement with PowerShell hardening scripts

6. Deploy the following PowerShell scripts to supplement the baseline:
   - [OfficeMacroHardening-PreventActivationofOLE.ps1](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE.ps1)  
   - [UserApplicationHardening-RemoveFeatures.ps1](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/scripts/UserApplicationHardening-RemoveFeatures.ps1)  
   These scripts are referenced remotely in the source material. [^1]  
7. Add each script as a PowerShell script in Intune and assign to the appropriate deployment group. For script usage and configuration options, refer to the script references in the source documentation. [^1]

### Verification and validation

8. Validate that web browsers, Office, and PDF security settings cannot be changed by users when the baseline is applied. This enforcement is provided by the Intune security baseline approach. [^1]
