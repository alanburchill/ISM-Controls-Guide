## Summary

Import the OfficeMacroHardeningPreventActivationOfOle.ps1 script into Intune using the Scripts option to prevent activation of OLE packages in Microsoft Office. Run this script using the logged-on credentials, with script signature checks not enforced, and do not run the script in a 64-bit PowerShell host. Assign the script to All Office Users to apply the setting across the organization. Note that the script is for Office 2016 and later; a separate Office2013 variant is provided for Office 2013.[^1]

## Implementation Steps

### Deploy Office Macro Hardening Script via Intune Scripts

1. Import the PowerShell script to prevent activation of Object Linking and Embedding packages. Use the file:
   - [OfficeMacroHardening-PreventActivationofOLE.ps1](https://github.com/microsoft/Intune-ACSC-Windows-HardeningGuidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE.ps1)[^1]

2. Run this script using the logged on credentials: Yes.[^1]

3. Enforce script signature check: No.[^1]

4. Run script in 64-bit PowerShell Host: No.[^1]

5. Assign the PowerShell script to: All Office Users (created in Stage 1).[^1]

6. Office 2013 alternative: For Office 2013, use the separate script [OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1](https://github.com/microsoft/Intune-ACSC-Windows-HardeningGuidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE-Office2013.ps1).[^1]
