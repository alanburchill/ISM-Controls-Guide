## Summary

Patches for operating systems on workstations, non-internet-facing servers, and non-internet-facing network devices must be applied within 48 hours of release when vulnerabilities are assessed as critical or exploits exist.[^1] Push these patches with Intune expedited updates using Windows Autopatch to accelerate deployment and coverage.[^2][^3] Autopatch uses deployment rings (Test, First, Fast, Broad) to stage updates and provides CVE visibility via the CVEs report.[^3][^4]

## Design Decision

> [!NOTE] Push critical OS patches within 48 hours using Intune expedited updates via Windows Autopatch. This design ensures rapid remediation for workstations and non-internet-facing devices per ImplementationGuidance.

## Prerequisites

* **Licensing:** Windows Autopatch license is required. The organization must have one of the following subscriptions that include Windows Autopatch: Windows Enterprise E3 or E5 (included in Microsoft 365 F3, E3, or E5); Windows Education A3 or A5 (included in Microsoft 365 A3 or A5); Windows Virtual Desktop Access E3 or E5; Microsoft 365 Business Premium. [^2]

* **Permissions/Roles:** Use roles with the fewest permissions; minimize the number of Global Administrators. [^2]

* **Dependencies:** 
  - Devices must be enrolled in Intune and be Microsoft Entra joined or Microsoft Entra hybrid joined. [^2]
  - Devices must be configured to receive Quality Updates directly from the Windows Update service. [^2]
  - Update Health Tools must be installed (KB 4023057). [^2]
  - Supported Windows versions are those that remain in servicing, on x86 or x64 architecture. [^2]
  - Supported Windows editions are Pro, Enterprise, Education, Pro Education, Pro for Workstations. [^2]

## Implementation Steps

### Push critical OS patches within 48 hours using Intune expedited updates using Windows Autopatch

1. Verify prerequisites and licensing.
   - Ensure Windows Autopatch licensing is in place (e.g., Windows 10/11 Enterprise E3/E5 or equivalent) and that devices are enrolled in Intune and joined to Entra ID.
   - Ensure devices are configured to receive quality updates directly from Windows Update.
   - Install Update Health Tools on endpoints (KB 4023057) as applicable. [^2]

2. Prepare Windows Autopatch enrollment.
   1. As a Global Administrator, sign into Intune.
   2. In the left navigation, go to Tenant administration > Windows Autopatch > Tenant enrollment.
   3. Run the Readiness assessment. The tool checks Intune and Entra ID settings to confirm deployment rings for Windows 10 or later and minimum administrator requirements; it provides a readiness report. [^2]
   4. Resolve any issues identified by the readiness assessment to reach a ready state, then proceed with enrollment.

3. Add admin contacts for each area of focus.
   1. Sign into Intune.
   2. Under Tenant administration > Windows Autopatch > Admin contacts, select Add.
   3. Enter contact details (name, email, phone, preferred language) and select an Area of focus.
   4. Enter details of the contact’s knowledge and authority for the chosen area of focus.
   5. Select Save to add the contact.
   6. Repeat for each area of focus. [^2]

4. Register devices with Windows Autopatch.
   1. Identify devices to be managed by Windows Autopatch and add them into the Windows Autopatch Device Registration group.
   2. Windows Autopatch performs device readiness checks, calculates deployment rings, assigns devices to a deployment ring, and assigns devices to other required groups.
   3. Devices are marked as active for management and updated deployment reports are generated for monitoring. [^1]

5. Create and assign expedited quality updates policy.
   1. Sign in to the Intune admin center.
   2. Navigate to Devices > Manage updates > Windows 10 and later updates > Quality updates tab > Create profile.
   3. In Settings, provide a name for the policy.
   4. In Settings, configure Expedite installation of quality updates for the update you want to expedite (the update is identified by its release date). Only updates that can be expedited are shown. Windows Update will apply the expedited update to devices with matching OS/version. [^2]
   5. In Settings, configure the number of days to wait before a forced reboot. This setting may be set from 0 to a higher value; a value of 0 means immediate restart after installation. [^2]
   6. In Assignments, add groups containing all applicable Windows devices.
   7. In Review + create, select Create to publish the policy.
   8. Important: Expedited policies override existing update deferrals. If you set the restart deadline to 0, devices will restart immediately after installation. [^2]

6. Monitor results and adjust.
   1. In the Intune admin center, go to Reports > Windows updates.
   2. Open the Windows Expedited Quality updates reports to view current deployment status.
   3. Use the Summary and detail views to identify devices installed, in progress, or with errors, and adjust policy or group assignments as needed. [^2]
