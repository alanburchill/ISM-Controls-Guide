## Summary

Regularly review the detected EOS software inventory on all devices via the Microsoft Defender admin portal to identify software that needs removal[^1]. Then use the current deployment mechanism to remove the software as required[^1]. The target software includes office productivity suites, web browsers and their extensions, email clients, PDF applications, Adobe Flash Player, and security products that are no longer supported by vendors[^1].

## Implementation Steps

### Regular review and removal of end-of-support software

1. Open the Microsoft Defender portal and locate software with end-of-support (EOS) status:
   - If you're a Microsoft Defender XDR + Microsoft Defender for Identity preview customer, select Exposure management > Recommendations, and select Vulnerabilities on the left.
   - If you're an existing customer, select Endpoints > Vulnerability management > Recommendations. [^1]

2. Add a Tags filter, select one or more EOS tag options, and select Apply. [^1]

3. Review the list of recommendations related to software with ended support, software versions that are end of support, or versions with upcoming end of support. These tags are visible in the [software inventory](tvm-software-inventory) page. [^1]

4. Open the version distribution to view end-of-support details:
   - A message appears in the security recommendation flyout for software with EOS.
   - Select the version distribution link to go to the software drill-down page.
   - There, you can see a filtered list of versions with tags identifying them as end of support, or upcoming end of support. [^1]

5. Decide whether to update or remove the EOS software from your organization. [^1]

6. Use the current deployment mechanism to remove the EOS software from devices as required. [^1]
