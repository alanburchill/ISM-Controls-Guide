## Summary

Onboard devices to Microsoft Defender for Endpoint to enable Defender Vulnerability Management to monitor firmware vulnerabilities across the environment.[^1] Then use the Defender portal's Exposure management section, under Vulnerability management, to view the Vulnerabilities list for CVEs, severities, and affected devices.[^2]

## Design Decision

> [!NOTE] Onboard devices to Microsoft Defender for Endpoint and use Exposure management > Vulnerabilities in the Defender portal to monitor and remediate vulnerabilities.

## Prerequisites

* **Licensing:** MDVM features require appropriate Microsoft Defender licensing (Defender for Endpoint P1). [^2]
* **Permissions/Roles:** Use established MDVM permissions or the new unified Exposure Management RBAC roles. [^2]
* **Dependencies:** Devices onboarded to Microsoft Defender for Endpoint; Access to the Microsoft Defender portal (Exposure management > Vulnerability management > Vulnerabilities). [^1]

## Implementation Steps

### Onboard devices to Defender for Endpoint

1. Create a new Windows Configuration Profile with a type of Template > Microsoft Defender for Endpoint (desktop devices running Windows 10 or later). 2. Set Expedite telemetry reporting frequency to Enable. 3. Assign the profile to a group containing all applicable Windows devices.  
   [^2]

> Onboarding endpoints to Defender for Endpoint enables Defender Vulnerability Management to continuously monitor and detect risk across the organization’s devices.  [^2]

### View vulnerabilities in Microsoft Defender portal

1. In the Microsoft Defender portal, select Exposure management > Vulnerability management > Vulnerabilities. 2. Review the vulnerabilities list; CVEs are shown with associated details, including severity and exposed devices. 3. If a security update is available, select the related security recommendation for remediation details.  
   [^1]

> For each CVE, you can see a list of the exposed devices and the affected software.  [^1]
