# Only Microsoft Office macros running from within a sandboxed environment, a Trusted Location or that are digitally signed by a trusted publisher are allowed to execute. (ISM-1674)

## Summary

Only macros that are digitally signed by a trusted publisher or located in a Trusted Location are allowed to execute; macros from files originating from the internet are blocked by default.[^1][^2] Implement this by configuring Intune policy to block macros by default with an All Macros Disabled policy and exclude a group for trusted publishers (Allow macro execution - Trusted Publisher) so macros signed by trusted publishers can run.[^3]

## Design Decision

> [!NOTE] Allow only macros signed by trusted publishers via Intune policy; unsigned macros are blocked.

## Prerequisites

* **Licensing:** Not provided in source documentation. [^1]
* **Permissions/Roles:** Administrative access to Microsoft Intune is required to create, import, and deploy policy sets. [^1]
* **Dependencies:** ACSC Office Hardening Guidelines policy JSON file; PowerShell script "OfficeMacroHardening-PreventActivationofOLE.ps1"; Graph Explorer access; Macros Enabled for Trusted Publishers policy JSON. [^1][^2][^4]

## Implementation Steps

### Controlling macro execution

1. Create a group that contains users that are able to run Office macros if they're signed by a Trusted Publisher. This group is referred to as: **Allow macro execution - Trusted Publisher**. [^4]

2. Save the [All Macros Disabled.json policy](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/All%20Macros%20Disabled.json) to your local device. [^5]

3. Navigate to the Microsoft Intune console. [^3]

4. Import a policy, under **Devices > Windows > Configuration profiles > Create > Import Policy**. [^3]

5. Name the policy, select Browse for files under Policy file and navigate to the saved policy from step 2. [^3]

6. Select **Save**. [^3]

7. Assign the All Macros Disabled policy to **All Office Users** (that was created at the start of this document). [^3]

8. Exclude the **Allow macro execution - Trusted Publisher** group (from step 1). [^3]

> This workflow blocks macros by default and allows, only for the dedicated group, macros signed by a Trusted Publisher. It relies on Intune configuration policies and the ACSC hardening guidance. [^1] [^2]

### Trusted Publisher

Implementation details – Macros Enabled for Trusted Publishers policy

1. Save the [Macros Enabled for Trusted Publishers.json policy](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/Macros%20Enabled%20for%20Trusted%20Publishers.json) to your local device. [^6]

2. Navigate to the Microsoft Intune console. [^3]

3. Import a policy, under **Devices > Windows > Configuration profiles > Create > Import Policy**. [^3]

4. Name the policy, select Browse for files under Policy file and navigate to the saved policy (from step 1). [^3]

5. Select **Save**. [^3]

6. Assign the policy to the group: **Allow macro execution - Trusted Publisher**. [^3]

7. After importing the Trusted Publisher policy, specify one or more Trusted Publishers. To add a Trusted Publisher, follow the instructions for adding a certificate to the Trusted Publishers certificate store using Intune. [^4]

8. Create a new policy for each Trusted Publisher, rather than bundling multiple publishers in the same policy. Deploy any Trusted Publishers certificate policies to the same group: **Allow macro execution – Trusted Publisher**. [^4]

9. Note: When signing macros, use the more secure version of the VBS project signature scheme: V3 signature. [^4]

> Restrict macro execution to digitally signed macros from trusted publishers to realize the ISM control objective. [^4]
