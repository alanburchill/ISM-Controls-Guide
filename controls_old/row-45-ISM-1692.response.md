## Summary

Patches for vulnerabilities in office productivity suites, web browsers and their extensions, email clients, PDF software, and security products are applied within 48 hours of release when vulnerabilities are assessed as critical or when working exploits exist, using Defender vulnerability management to identify vulnerabilities and Intune deployment to push patches.[^1]

Configure and enable Windows Autopatch for all workstations via the InTune admin portal to automate updates; for third-party applications, deploy new versions via Intune Enterprise Application Catalogue, or repackage and redeploy all applications that require security updates within the required timeline.[^2]

For Edge, configure all devices to the "Targe Channel" or "Stable" to ensure timely Edge updates via Autopatch.[^3]

## Design Decision

> [!NOTE] Enable Windows Autopatch for all workstations via the InTune admin portal. Deploy updated third-party applications through the InTune Enterprise Application Catalogue, or repackage and redeploy any apps requiring security updates within the defined timeline. Configure Edge to the Stable channel on all devices.

## Prerequisites

* **Licensing:** Windows Autopatch features require licenses available with Business Premium, A3+, E3+, or F3. [^2]
* **Permissions/Roles:** 
  1. Access to the Microsoft Intune admin center to configure Windows Autopatch groups and Edge updates. [^2]
  2. Access to the Microsoft Defender Vulnerability Management portal; must be in the Security Reader role to access the portal. [^1]
* **Dependencies:** 
  1. Microsoft Intune service is required to deploy Autopatch and manage applications. [^2]
  2. Defender Vulnerability Management licensing (or Defender for Endpoint Plan 2 or E5) is required for vulnerability management capabilities. [^1]
  3. Devices must be onboarded to Defender for Endpoint to enable DVM. [^1]
  4. For third-party applications, use Intune Enterprise Application Management (catalog) for deploying new versions; otherwise, repackaging and redeploying applications is required. [^1]
  5. Edge updates are configured via Autopatch groups (Edge update policies). [^3]

## Implementation Steps

### Windows Autopatch Deployment and Edge Channel Configuration

1. In the Microsoft Intune admin center, go to Tenant Administration > Windows Autopatch > Autopatch groups. Create or select an Autopatch group for the target workstations. [^2]
2. For the selected Autopatch group, enable Microsoft Edge updates. Click Update types > Edit, then select Microsoft Edge updates. [^3]
3. Configure deployment and release settings. Click Next: Deployment settings, Next: Release schedules, Next: Review + save, then Save. [^3]
4. Remove conflicting Edge update policies to avoid policy conflicts. In Devices > Manage devices > Configuration > Policies, delete:
   - Windows Autopatch - Microsoft Edge Update Channel Beta
   - Windows Autopatch - Edge Update Channel Stable
   Note: If Edge updates were previously configured, Autopatch may retain policies. [^3]
5. Verify Edge update policies are in effect. For each Autopatch group, ensure the Microsoft Edge Update Type checkbox is selected. In Devices > Manage devices > Configuration > Policies, confirm a policy named: Windows Autopatch Microsoft Edge Update Policy - <group name> - <ring name> exists. [^3]
6. Confirm removal of old Edge policies. Use the policy list search to ensure no Edge Update Channel policies remain (0 profiles filtered). [^3]
7. Ensure the Edge Update policies are created and visible. The expected policy names are: Windows Autopatch Microsoft Edge Update Policy - <group name> - <ring name>. [^3]
8. Edge channel configuration. Ensure Edge is updated via Stable Channel (or Target Channel as appropriate). Windows Autopatch configures Edge updates to the Stable Channel by default. [^3]

Notes:
- Windows Autopatch uses the Stable Channel for Microsoft Edge updates. This behavior is described in the Edge Autopatch documentation. [^3]
- The Autopatch documentation covers enrollment, groups, update rings, and Edge update capabilities available through the Intune portal. [^2]
