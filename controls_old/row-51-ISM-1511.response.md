## Summary

Backups of data, applications, and settings are performed and retained in accordance with business criticality and business continuity requirements.[^1] Microsoft 365 Backup protects SharePoint, OneDrive, and Exchange Online data within the Microsoft 365 boundary, offering fast restore and a 1-year retention for each workload.[^2] On-premises servers and Azure VMs are backed up with the Microsoft Azure Recovery Services (MARS) agent, with options to integrate with on-premises backup servers (MABS or DPM) for broader coverage.[^1]

## Design Decision

> [!NOTE] Adopt a tiered backup design aligned to workload criticality across Workstations, On-Prem/Azure servers, and Microsoft 365 workloads. Workstations: enable "Windows Backup and Restore" enrollment, turn on the "Show restore page", and configure OneDrive for Business to be automatically enabled with Known Folder Backup. On-Prem Servers: enable the Microsoft Azure Recovery Services agent to protect on-premises systems; Azure Servers: use the Microsoft Azure Recovery Services agent to back up Azure VMs; Microsoft 365: backup SharePoint, Exchange Online, and OneDrive using "Microsoft 365 Backup".

## Prerequisites

* **Licensing:** A valid Azure subscription with an associated resource group and region; an owner or contributor must be assigned to the subscription; Pay-as-you-go billing for Microsoft 365 Backup must be activated. [^4]

* **Permissions/Roles:** Global Administrator or SharePoint Administrator privileges are required to access the Microsoft 365 admin center and enable Microsoft 365 Backup. [^4]

* **Dependencies:** Microsoft 365 Backup is not available for Government Community Cloud (GCC) environments; ensure the service is available for the tenant. Also requires an Azure subscription with billing configured as described. [^2][^4]

### Microsoft 365 Backup

1. Turn on Microsoft 365 Backup
   1. In the Microsoft 365 admin center, select Setup.
   2. Under Billing and licenses, select Activate pay-as-you-go services.
   3. On the Activate pay-as-you-go services page, select Get started.
   4. On the Pay-as-you-go services page, select Syntex services.
   5. On the Syntex page, in the Storage section, select Backup.
   6. On the Backup panel, select Turn on.
   7. On Turn on Backup panel, review the applicable terms of service, and then select Save.[^4]

2. Enable email notifications
   1. Sign in to the Microsoft 365 admin center as a Global admin, Microsoft 365 Backup admin, SharePoint admin, or Exchange admin.[^4]
   2. Go to the Manage notifications option on the Backup panel, or the Email notifications option on the Microsoft 365 Backup home page.
   3. Turn on notifications.
   4. Add users, distribution lists, or security groups (email enabled) to the Backup Notification List.
   5. (Optional) Select the checkbox to also receive routine event notifications.
   6. Save your changes.[^4]

3. Create backup policies to protect your data
   1. Go to the Microsoft 365 admin center.[^4]
   2. Select Settings.[^4]
   3. Select Microsoft 365 Backup from the list of products.[^4]
   4. Create backup policies for OneDrive, SharePoint, or Exchange (backup-view-edit-policies?view=o365-worldwide).[^4]

4. Admin roles and backup management privileges
   - Global Administrator: OneDrive, SharePoint, Exchange — all enabled.[^4]
   - SharePoint Administrator: OneDrive, SharePoint.[^4]
   - Exchange Administrator: Exchange only.[^4]
   - Microsoft 365 Backup Administrator: OneDrive, SharePoint, Exchange.[^4]
