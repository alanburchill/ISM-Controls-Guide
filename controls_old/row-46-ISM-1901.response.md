## Summary

Enable and configure Windows Autopatch for all workstations through Intune to automate patching across Windows, Microsoft 365 Apps, Edge, and Teams.[^1]

Deploy new versions of third-party applications via the Intune Enterprise Application catalog; if updates are not available, repackage and redeploy affected applications within the required timeline.[^5]

Configure Edge to use the Target Channel or Stable channel to manage Edge updates.[^1]

Patches for office productivity suites, web browsers and their extensions, email clients, PDF software, and security products are applied within two weeks of release when vendor advisories are noncritical and no working exploits exist.[^3]

## Design Decision

> [!NOTE] Enable Windows Autopatch for all workstations via the Intune admin portal to automate Windows, Microsoft 365 Apps for Enterprise, and Edge updates. Deploy new versions of third-party applications via the Intune Enterprise Application Catalogue; otherwise repackage and redeploy applications that require security updates within the defined timeline. Configure Edge to the Stable channel (or Target Channel) to align with patch cadence.

## Prerequisites

* **Licensing:** Windows Autopatch is included with Business Premium, A3+, E3+, and F3 licenses.[^1]
* **Permissions/Roles:** Microsoft recommends that you use roles with the fewest permissions. Minimizing the number of users with the Global Administrator role helps improve security for your organization.[^1]
* **Dependencies:** Intune or Microsoft Graph to manage Windows Autopatch; Windows Autopatch is embedded in Intune.[^2]

## Implementation Steps

### Enable Windows Autopatch via Intune and prepare deployment

1. Run the Windows Autopatch readiness assessment.
   - Sign in to Intune as a Global Administrator.
   - Navigate to Intune > Tenant administration > Windows Autopatch > Tenant enrollment.
   - Run the readiness assessment and review the report. Resolve issues per the guidance to reach a ready state. [^2]

2. Add admin contacts for Autopatch areas.
   - In Intune, go to Tenant administration > Windows Autopatch > Admin contacts.
   - Click Add.
   - Enter name, email, phone number, and preferred language.
   - Select an Area of focus and provide details of knowledge and authority.
   - Save and repeat for each area of focus. [^2]

3. Register devices to Windows Autopatch.
   - Review device registration prerequisites.
   - Identify devices and add them to the Windows Autopatch Device Registration Microsoft Entra group.
   - Autopatch performs readiness checks, calculates deployment rings, assigns devices to rings and groups, and marks devices as active for management.
   - Monitor device registration trends and update reports. [^2]

4. Create and configure an Autopatch group for deployment.
   - In Intune, go to Tenant administration > Windows Autopatch > Autopatch groups > Create.
   - Basics: provide a name and description. Next to Deployment rings. [^5]
   - Deployment rings: Add deployment rings. For each ring, assign groups and configure distribution (Dynamic groups or Assigned groups). Use Dynamic groups to distribute devices by percentage, or assign explicit groups to rings. [^5]
   - Assigned group distribution: Add group to ring for rings that support Assigned distribution. [^5]
   - Update types: Select the types to deploy (Quality updates, Feature updates, Driver updates, Microsoft 365 Apps updates, Microsoft Edge updates). [^5]
   - Deployment settings: If Quality updates and Microsoft 365 Apps updates are selected, they deploy automatically. Set Edge updates channel to Stable. Configure other update types as needed (e.g., driver update approvals). [^5]
   - Release schedules: Choose a release schedule preset (Information worker, Shared device, Kiosks and billboards, Reboot-sensitive devices). [^5]
   - Scope tags: Apply as needed. [^5]
   - Review + create: Review changes and create the Autopatch group. [^5]
   - Important: Do not modify the Microsoft Entra group membership types after creation. Ensure groups are configured correctly for ring distribution. [^5]
   - Important: A device-based Entra group can be used with only one deployment ring at a time. [^5]

5. Confirm Edge browser channel configuration.
   - In the Autopatch group update settings, ensure Edge updates are configured to the Stable channel. This aligns with Edge progressive rollout behavior. [^1]

6. For third-party applications, deploy updates via Intune Enterprise App Management.
   - Use Intune’s enterprise application management workflow to deploy updated versions of third-party apps.
   - If updates are not available in the catalog, repackage and redeploy the affected applications within the required timeline. [^3]
