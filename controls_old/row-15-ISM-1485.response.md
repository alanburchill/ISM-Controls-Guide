## Summary

Edge policy is implemented via the Microsoft Edge security baseline deployed through Intune to block intrusive ads.[^2]

The baseline provides Level 2 enhanced security and includes privacy protections, such as disabling ad personalization and anti-tracking features.[^1]

After deployment, verify that the baseline is applied by reviewing device status in Endpoint security and validating Edge policy on devices via edge://policy.[^2]

## Design Decision

> [!NOTE] Enable Edge policy to block intrusive ads using Intune security baseline.

## Implementation Steps

### Enable Edge policy to block intrusive ads via Intune security baseline

1. In the Microsoft Intune admin center, navigate to Endpoint security > Security baselines > Security Baseline for Microsoft Edge > Create policy > Create.[^2]
2. On the Basics tab:
   - Name: Microsoft Edge Security Baseline - Level 2
   - Description: Microsoft Edge security baseline providing Level 2 enhanced security
   [^2]
3. Select Next. In Configuration settings, expand Microsoft Edge and review the preconfigured settings. All settings are preconfigured to Microsoft-recommended values. You can accept the defaults or customize specific settings based on organizational requirements. For privacy and ad-related controls, prefer the following:
   - Privacy & Data: Allow personalization of ads, search, and news — Disabled
   - Block tracking of users' web-browsing activity — Balanced
   [^2]
4. Select Next.
5. For Scope tags, select the appropriate scope tag.
   [^2]
6. For Assignments, assign to SEB-Level2-Devices group.
   [^2]
7. Select Next to review the settings. Then choose Create.
   [^2]
