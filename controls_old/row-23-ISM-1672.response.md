## Summary

Enable macro antivirus scanning using Intune and Defender Antivirus settings.[^1] The policy enforces a runtime AV scan for macros with scope enabled for all documents and requires Defender to be running on the device.[^1] Macros are scanned by Defender before execution as part of the ACSC Office Hardening Guidelines.[^1]

## Design Decision

> [!NOTE] Enable macro antivirus scanning using Intune and Defender AV settings to enforce macro protection for Microsoft Office documents.

## Prerequisites

* **Licensing:** Not provided in source documentation. [^1]
* **Permissions/Roles:** Not provided in source documentation. [^1]
* **Dependencies:** Requires Windows Defender Antivirus to be running on the device. [^1]

## Implementation Steps

### Enable Macro Antivirus Scanning via Intune and Defender AV

1. Save the ACSC Office Hardening Guidelines policy to your local device.  
   Reference policy file: ACSC Office Hardening Guidelines.json  
   Link: https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/policies/ACSC%20Office%20Hardening%20Guidelines.json.  [^1]

2. Import the ACSC policy into Intune.  
   Steps:  
   - In Intune, navigate to Devices > Windows > Configuration profiles > Create > Import Policy.  
   - Name the policy, browse for the saved policy file, and Save.  [^1]

3. Import the PowerShell script to prevent activation of OLE packages.  
   Script: OfficeMacroHardening-PreventActivationofOLE.ps1  
   Link: https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/office/scripts/OfficeMacroHardening-PreventActivationofOLE.ps1.  
   Steps:  
   - In Intune, go to Devices > Scripts and create a new PowerShell script.  
   - Import the script, run it with logged-on credentials: Yes.  
   - Enforce script signature check: No.  
   - Run script in 64-bit PowerShell Host: No.  
   - Assign the script to All Office Users.  [^1]

4. Stage 1: Create a policy to target All Office Users and prepare Microsoft 365 Apps deployment.  
   Steps:  
   - Create a policy to contain the All Office Users group.  
   - Create Microsoft 365 Apps for Windows 10 or later under Apps > Windows > Add > Microsoft 365 Apps, and include required apps.  
   - Set Architecture to 64-bit (recommended).  
   - Set Update Channel to Semi-Annual Enterprise Channel (recommended).  
   - Do not assign the application yet.  [^1]

5. Stage 3: Create a policy set that combines Microsoft 365 Apps with the ACSC Office Hardening policy.  
   Steps:  
   - Navigate to Devices > Policy sets > Create.  
   - Under Application Management > Apps, select Microsoft 365 Apps (for Windows 10 and later) (created in Stage 1).  
   - Under Device Management > Device Configuration Profiles, select ACSC Office Hardening (created in Stage 2).  
   - Under Assignments, select All Office Users (created in Stage 1).  
   - Import the Endpoint Security Attack Surface Reduction (ASR) policy.  
   - Use Graph Explorer to authenticate and create an instance using the beta schema:  
     https://graph.microsoft.com/beta/deviceManagement/templates/0e237410-1367-4844-bd7f-15fb0f08943b/createInstance  
     Paste the ASR policy JSON from the referenced guideline, and assign the policy to All Office Users.  
     Note: The ASR policy is configured in audit mode.  [^1]

6. Validate macro antivirus scanning is enabled.  
   The ACSC Office Hardening Guidelines policy configures:  
   - Force Runtime AV Scan: Enabled  
   - Macro Runtime Scan Scope: Enabled for all documents  
   Prerequisite: Windows Defender must be running on the device.  [^1]

7. Documentation and verification references.  
   Review the Defender for Endpoint integration and threat review guidance as needed to verify macro activity and scanning outcomes.  [^1]
