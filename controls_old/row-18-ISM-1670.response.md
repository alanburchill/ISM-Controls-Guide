## Summary

PDF applications are blocked from creating child processes.[^2] Enable the Attack Surface Reduction rule Block Adobe Reader from creating child processes through Intune.[^1] This approach aligns with Microsoft Intune ASR guidance and Essential Eight hardening guidance.[^1][^2]

## Design Decision

> [!NOTE] Enable the ASR rule to block Adobe Reader from creating child processes via Intune.

## Implementation Steps

### Block Adobe Reader from creating child processes

1. In Intune, navigate to Endpoint Security > Attack Surface Reduction.  
2. Create (or modify) a new Attack Surface Reduction Endpoint Security Policy.  
3. Set Block Adobe Reader from creating child processes to Enable.  
4. Assign the Attack Surface Reduction Rule policy to a group.[^3]
