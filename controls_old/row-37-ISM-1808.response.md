## Summary

Onboard devices to Microsoft Defender for Endpoint.[^1] Then use the Defender security portal report under Exposure management > Vulnerability management to view vulnerabilities.[^3] Defender Vulnerability Management provides asset visibility, up-to-date vulnerability data, and risk-based prioritization, enabling remediation workflows and the creation of remediation tasks in Intune.[^3]

## Design Decision

> [!NOTE] Onboard devices to Microsoft Defender for Endpoint. Then use the 'Microsoft Defender' security portal report under Exposure management > Vulnerabilities to identify and monitor vulnerabilities.

## Prerequisites

* **Licensing:** Microsoft Defender Vulnerability Management (DVM), a standalone offering, or Microsoft Defender for Endpoint Plan 2 or E5 license provides subset of core vulnerability management capabilities. Full capabilities of DVM are available as an add-on. [^1]

* **Permissions/Roles:** Access to the Microsoft Defender portal requires membership in the Security Reader AD built-in role. [^1]

* **Dependencies:** 
  1) Devices must be onboarded to Microsoft Defender for Endpoint. If not onboarded, DVM requires Defender for Endpoint running in block mode (passive). Onboarding can be accomplished via Group Policy, Endpoint Manager, or local scripts. [^1]
  2) For server resources, Defender for Cloud plan must be enabled for servers or the servers onboarded to Defender for Endpoint. [^1]
  3) To view vulnerabilities in Defender, navigate to Exposure management > Vulnerability management > Vulnerabilities. [^3]

## Implementation Steps

### Onboard devices to Defender for Endpoint and access Defender Vulnerability Management

1. Onboard devices to Microsoft Defender for Endpoint using the recommended onboarding methods (Group Policy, Microsoft Endpoint Manager, or local scripts). See the onboarding guidance linked in the source documentation. [^1]

2. If devices are not onboarded to Defender for Endpoint, ensure Defender for Endpoint is running in block mode (i.e., not fully enabled) to support Defender Vulnerability Management (DVM). [^1]

3. If onboarding to Defender for Endpoint is in place, onboard the devices to Defender Vulnerability Management (DVM) as described in the Defender for Endpoint guidance. Licensing prerequisites may apply. [^1]

4. Access the Defender Vulnerability Management features in the Microsoft Defender portal. The portal provides asset visibility, vulnerability assessments, and remediation workflow. [^3]

5. If you plan to use the remediation workflow, enable the Microsoft Intune connection in the Defender portal:
   - In the Defender portal, navigate to Settings > Endpoints > General > Advanced features.
   - Turn the Microsoft Intune connection On. [^3]

6. Navigate to the Vulnerability Management area to view vulnerability data and recommendations:
   - Open Exposure management > Vulnerability management > Vulnerabilities (or Recommendations as applicable). [^4]

7. Use the vulnerability management dashboard and software inventories to identify exposed software and devices, then proceed with remediation actions as needed. [^5]
