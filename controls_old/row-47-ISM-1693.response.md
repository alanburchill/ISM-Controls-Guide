## Summary

Patches, updates or other vendor mitigations for vulnerabilities in applications other than office productivity suites, web browsers and their extensions, email clients, PDF software, and security products are applied within one month of release.[^1]

Configure Windows Autopatch for all workstations via the Intune admin portal and deploy third-party application patches through the Intune Enterprise Application Catalogue, re-packaging and redeploying updates as needed to meet the one-month timeline.[^3][^1]

For the Edge web browser, configure all devices to the "Target Channel" or "Stable" to receive timely security updates.[^2]

## Design Decision

> [!NOTE] Enable Windows Autopatch for all workstations via the Intune admin portal to automate patching of Windows and Microsoft 365 Apps. Deploy third-party application patches through the Intune Enterprise Application Catalogue; if patches are not available, repackage and redeploy affected applications within the required timeline. Configure Microsoft Edge to use the Stable channel (or Extended Stable via the Target Channel override) to align with patching cadence.

## Prerequisites

* **Licensing:** Windows Autopatch features require a qualifying license. They are available to Business Premium and A3+ licenses; features included with Business Premium, A3+, E3+, and F3 licenses. [^3]
* **Permissions/Roles:** Role-based access control is available for Windows Autopatch administration in Intune. [^3]
* **Dependencies:** Devices must be enrolled in Intune or managed using co-management (Intune + Configuration Manager). [^4]

## Implementation Steps

### Windows Autopatch enrollment and device patching

1. Ensure all workstations are enrolled in Intune and Windows Autopatch is configured in the Intune admin portal. [^3][^4]
2. Create Autopatch groups and Update rings in Intune to define deployment sequences. [^3]
3. Enable Windows Autopatch for all devices and verify enrollment status in the Intune portal. [^3]
4. Monitor update activity and device health using Intune reports. [^4]

### Third-party applications patching via Intune Enterprise Application Catalogue

1. Use Intune Enterprise Application Management to access the secure catalog of apps for patch management. [^1]
2. If a newer version patch is available in the catalog, deploy the patch via the Enterprise Application Catalogue. [^1]
3. If updates are not available in the catalog, repackage and redeploy all applications that require security updates within the timeline. [^1]
4. Validate patch deployment status and compliance using Intune reports. [^4]

### Edge browser channel configuration

1. Decide on the Edge channel: Target Channel (or Stable). For a controlled rollout, configure the Target Channel override to Stable; Extended Stable is an option if extended cadence is desired. See Edge channel overview. [^2]
2. In Intune, configure Microsoft Edge update policies to set the Target Channel override accordingly. [^2]
3. Verify the channel setting in edge://settings/help to confirm the deployed channel. [^2]
