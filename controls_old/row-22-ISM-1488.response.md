## Summary

Microsoft Office blocks macros from files originating from the Internet by default, reducing exposure to malicious VBA code.[^1] To enforce this protection in an Intune-managed environment, enable the policy to block macros from running in Office files from the Internet as part of the Microsoft 365 Apps security baseline.[^2]

## Design Decision

> [!NOTE] Enable policy to block macros from running in Office files from the Internet in Intune. This blocks macros in internet-originated files by default, satisfying the control requirement.

## Prerequisites

* **Licensing:** Not provided in source documentation. [^1]
* **Permissions/Roles:** Access to Microsoft Intune admin center to configure and deploy policy settings on devices running Windows 10 or later. [^2]
* **Dependencies:** Cloud Policy service; Microsoft Intune; Security baseline for Office settings in Intune (security baseline v2 office settings); Windows 10 or later devices. [^3][^2]

## Implementation Steps

### Enable Block macros from internet-originated Office files in Intune

1. Apply the Microsoft 365 Apps for Enterprise security baseline in Intune. This baseline includes the policy to block macros from running in Office files from the Internet for all Office applications. [^2]

2. The baseline configures the policy per application. The Office apps covered include Access, Excel, PowerPoint, Project, Publisher, Visio, and Word. [^2]

3. If not using the security baseline, configure per-application policies via Cloud Policy in Intune. Create a policy configuration, assign it to a group, and select policies to include in the policy configuration. [^3]

4. Alternatively, in Intune you can configure Office macro blocking using the Settings catalog or Administrative Templates. To start, go to Devices > Configuration profiles > Create profile. Platform: Windows 10 and later; then choose the profile type. [^1]
