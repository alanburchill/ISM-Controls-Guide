## Summary

Patches for vulnerabilities in operating systems of workstations, non-internet-facing servers, and non-internet-facing network devices are applied within one month of release when vulnerabilities are noncritical and no working exploits exist. Implement a monthly patch cadence for these non-critical OS updates using the organization's update management tooling, aligning with the Essential Eight guidance for patching OS.  

## Design Decision

> [!NOTE] Implement a monthly patch cadence for non-critical OS updates via Intune Windows AutoPatch to ensure timely patching with minimal disruption.

## Prerequisites

* **Licensing:** Windows Autopatch is included with Windows 10/11 Enterprise E3 or higher.[^1]
* **Permissions/Roles:** Global Administrator role is used to run readiness assessment and enroll devices in Windows Autopatch workflow.[^1]
* **Dependencies:** Not provided in source documentation.[^1]

## Implementation Steps

### Maintain monthly patch cadence via Windows AutoPatch

1. Readiness assessment:
   1. As a Global Administrator, go to **Intune**.
   2. In the left pane, select **Tenant administration** and then navigate to **Windows Autopatch** > **Tenant enrollment**.[^1]

2. Admin contacts:
   1. Sign into Intune.
   2. Under **Tenant administration** in the Windows Autopatch section, select **Admin contacts**.
   3. Select **Add**.
   4. Enter the contact details including name, email, phone number and preferred language. For a support ticket, the ticket's primary contact's preferred language determines the language used for email communications.
   5. Select an [Area of focus](/en-us/windows/deployment/windows-autopatch/deploy/windows-autopatch-admin-contacts#area-of-focus) and enter details of the contact's knowledge and authority in the specified area of focus.
   6. Select **Save** to add the contact.
   7. Repeat for each area of focus.[^1]

3. Device registration:
   1. IT admin reviews Windows Autopatch device registration prerequisites prior to register devices with Windows Autopatch.
   2. IT admin identifies devices to be managed by Windows Autopatch and adds them into the Windows Autopatch Device Registration Microsoft Entra group.
   3. Windows Autopatch then:
      - Performs device readiness prior registration (prerequisite checks)
      - Calculates the deployment ring distribution
      - Assigns devices to a deployment ring, based on the previous calculation
      - Assigns devices to other Microsoft Entra groups required for management
      - Marks devices as active for management so it can apply its update deployment policies
      - IT admin then monitors the device registration trends and the update deployment reports
     The detailed device registration work flow can be found here.  
     [Windows Autopatch device registration overview](/en-us/windows/deployment/windows-autopatch/deploy/windows-autopatch-device-registration-overview#detailed-device-registration-workflow-diagram).[^1]

4. Autopatch dashboard and reporting:
   1. Sign into the Intune console.
   2. Navigate to **Reports** > **Windows Autopatch** > **Windows Quality Updates**.
   3. Use the All Devices Report to view update status per device, including:
      - Device name
      - Microsoft Entra device ID
      - Serial number
      - Deployment ring
      - Update status
      - Update sub status
      - OS version
      - OS revision
      - Intune last check-in time
     The All Devices Report contains these fields.[^1]
