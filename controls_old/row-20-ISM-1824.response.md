## Summary

PDF security settings are locked via Intune to prevent end users from altering them[^1]. This enforcement is provided by Intune security baselines, which apply and enforce the configured settings to ensure they cannot be changed by standard users[^2]. Tamper protection helps guard these security configurations from tampering by attackers[^3].

## Design Decision

> [!NOTE] Lock PDF security settings using Intune so users cannot change them.

## Implementation Steps

### Lock PDF security settings via Intune (ASR)

1. In Intune, navigate to Endpoint Security > Attack Surface Reduction.
2. Create (or modify) a new Attack Surface Reduction Endpoint Security Policy.
3. Set Block Adobe Reader from creating child processes to Enable.
4. Assign the Attack Surface Reduction Rule policy to a group. [^1]
