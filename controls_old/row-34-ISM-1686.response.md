## Summary

Credential Guard protects credentials by isolating them with virtualization-based security. Enable it via an Intune device configuration profile (Settings Catalog under Device Guard: Credential Guard, or a custom policy using the DeviceGuard CSP) with options Enabled with UEFI lock or Enabled without lock. After applying the policy, restart the device. Starting with Windows 11 22H2 and Windows Server 2025, Credential Guard is enabled by default on devices that meet hardware requirements.[^1]

## Design Decision

> [!NOTE] Enable Credential Guard via an Intune device configuration profile. Configure Credential Guard to "Enabled with UEFI lock" or "Enabled without lock" per deployment needs.

## Implementation Steps

### Configure Credential Guard with Intune

1. Create a Settings Catalog policy in Microsoft Intune and assign it to the devices group that requires Credential Guard configuration.[^1]

2. In the policy, configure the following settings:
   - Turn On Virtualization Based Security
     - OMA-URI: `./Device/Vendor/MSFT/Policy/Config/DeviceGuard/EnableVirtualizationBasedSecurity`
     - Data type: int
     - Value: `1`
   - Credential Guard Configuration
     - OMA-URI: `./Device/Vendor/MSFT/Policy/Config/DeviceGuard/LsaCfgFlags`
     - Data type: int
     - Value:
       - Enabled with UEFI lock: `1`
       - Enabled without lock: `2`
   - Note: If remote turn-off capability is desired, select the option **Enabled without lock**.[^1]

3. Alternatively, configure devices using a custom policy with the DeviceGuard Policy CSP. Refer to the DeviceGuard CSP documentation for enabling virtualization-based security.[^1](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-deviceguard#enablevirtualizationbasedsecurity)

4. After the policy is applied, restart the device.[^1]

5. Verify Credential Guard status:
   - System Information method:
     - Open System Information and check that Credential Guard appears as running under Virtualization-based Security Services. 
   - PowerShell method:
     - Run the command:
       ```
       (Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard).SecurityServicesRunning
       ```
       - Output of `1` indicates Credential Guard is enabled (running); `0` indicates disabled.[^1]
