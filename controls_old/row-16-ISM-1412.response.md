## Summary

Deploy the ACSC Edge hardening configuration through Intune to enforce enterprise browser controls. The hardening aligns with the Essential Eight guidance and uses ACSC Edge Hardening Guidelines imported into Intune, including applying the Edge Security Baseline to Microsoft Edge. When conflicting requirements exist, the most restrictive setting prevails. 

## Design Decision

> [!NOTE] Deploy ACSC Edge hardening configuration through Intune to enforce the Edge browser hardening baseline centrally.

## Prerequisites

* **Licensing:** EMS (Enterprise Mobility + Security) suite including Microsoft Intune and Microsoft Entra ID P1 or P2 features. [^2]
* **Permissions/Roles:** Intune administrator access required to configure and deploy policies in the Intune admin center. [^2]
* **Dependencies:** Intune service to deploy the ACSC Edge hardening configuration; Microsoft Edge Baseline/security policy; ACSC Edge Hardening Guidelines policy to be saved to local device; Intune Company Portal app required for unenrolled devices to apply app protection policies; Supported OS versions for Edge on iOS and Android: iOS 14.0+, Android 8.0+ for enrolled devices and Android 9.0+ for unenrolled devices. [^1][^2]

## Implementation Steps

### Deploy ACSC Edge hardening configuration through Intune

1. In the Microsoft Intune admin center, navigate to Endpoint Security > Security Baselines > Microsoft Edge Baseline. [^1]
2. Create a new Microsoft Edge Baseline by selecting Create Profile. [^1]
3. Review the configuration, and assign the Security Baseline to a deployment group. [^1]
4. Save the ACSC Edge Hardening Guidelines policy to your local device: [ACSC Edge Hardening Guidelines.json](https://github.com/microsoft/Intune-ACSC-Windows-Hardening-Guidelines/blob/main/edge/policies/ACSC%20Edge%20Hardening%20Guidelines.json). [^3]
5. In the Intune console, navigate to Devices > Windows > Configuration profiles > Create > Import Policy. [^1]
6. Name the policy, browse for the policy file, and navigate to the saved policy from step 4. [^1]
7. Select Save. [^1]
