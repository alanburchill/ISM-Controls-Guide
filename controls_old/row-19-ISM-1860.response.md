## Summary

PDF applications are hardened using ACSC Essential Eight guidance and vendor hardening guidance, with the most restrictive guidance taking precedence when conflicts occur.[^1] Implement vendor PDF hardening settings via Intune configuration profiles to enforce these controls.[^1] Intune-based mechanisms, including browser baselines and ASR policies, are used to apply and enforce PDF-related hardening as part of the overall user application hardening program.[^1]

## Design Decision

> [!NOTE] Apply vendor PDF hardening settings via Intune configuration profiles to align with vendor guidance and ASD requirements. When conflicts arise, enforce the most restrictive setting.

## Implementation Steps

### PDF software hardening via Intune Attack Surface Reduction

1. In the Intune admin center, navigate to Endpoint Security > Attack Surface Reduction.
2. Create (or modify) a new Attack Surface Reduction Endpoint Security Policy.
3. Set the setting to block Adobe Reader from creating child processes and enable it.
4. Assign the Attack Surface Reduction Rule policy to a deployment group. [^1]
