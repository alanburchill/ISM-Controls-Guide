## Summary

Patches, updates or other vendor mitigations for vulnerabilities in operating systems are applied within 48 hours of release when vulnerabilities are critical or exploits exist.[^1]

Push critical OS patches within 48 hours using Intune expedited updates via Windows Autopatch to accelerate deployment.[^3]

Windows Autopatch uses deployment rings (Test, First, Fast, Broad) to stage updates and provide monitoring and safeguards for expedited security updates.[^5]

## Design Decision

> [!NOTE] Push critical OS patches within 48 hours by using Intune expedited updates via Windows Autopatch to automate fast, vendor-recommended patching.

## Prerequisites

* **Licensing:** Windows Autopatch licensing required. Acceptable licenses include Windows Enterprise E3 or E5 (included in Microsoft 365 F3, E3, or E5), Windows Education A3 or A5 (included in Microsoft 365 A3 or A5), Windows Virtual Desktop Access E3 or E5, or Microsoft 365 Business Premium. [^5]

* **Permissions/Roles:** Use roles with the fewest permissions; minimize the number of users with Global Administrator role. [^2]

* **Dependencies:** 
  1. Devices must be enrolled in Intune MDM. [^4]
  2. Devices must be Microsoft Entra joined or Entra hybrid joined. [^4]
  3. Supported Windows editions: Pro, Enterprise, Education, Pro Education, Pro for Workstations. [^4]
  4. Windows 10/11 version 1709 or later. [^4]
  5. Devices must be configured to receive Quality Updates directly from the Windows Update service. [^4]
  6. Have Update Health Tools installed (KB 4023057). [^4]
  7. Endpoints must be accessible; refer to the Windows Autopatch network endpoints documentation. [^2]

## Implementation Steps

### Expedite Windows quality updates via Intune and Windows Autopatch

Push critical OS patches within 48 hours using Intune expedited updates, leveraging Windows Autopatch.[^1]

Prerequisites
- Licensing: Windows Autopatch license is required (Windows 10/11 Enterprise E3/E5, Education A3/A5, or equivalent) and must be active for expedited patching.[^3]
- Devices must be enrolled in Intune and joined to Microsoft Entra (or hybrid joined). They must be configured to receive quality updates from Windows Update.[^3]
- Update Health Tools must be installed on devices (KB 4023057 or equivalent).[^3]

```powershell
### Check for the Microsoft Update Health Service; if found, no remediation is needed.
if (Get-Service -Name "Microsoft Update Health Service" -ErrorAction SilentlyContinue) {
    Write-Host "Microsoft Update Health Service is present."
    Exit 0
} else {
    Write-Host "Microsoft Update Health Service is missing."
    Exit 1
}
```

1. Sign in to the Microsoft Intune admin center.
2. Navigate to Devices > Manage updates > Windows 10 and later updates > Quality updates tab > Create profile.
3. In Settings, enter a name for the profile.
4. In Settings, configure Expedite installation of quality updates if device OS version is less than the selected update.
5. In Settings, configure the number of days to wait before forced reboot.
6. In Assignments, select Add groups and assign the profile to a group containing all applicable Windows devices.
7. In Review + create, select Create.

Notes
- Expedited updates override deferrals to expedite deployment of the selected update. This approach focuses on timely installation for critical vulnerabilities. Ensure Autopatch readiness and licensing are in place before deployment.[^1]
