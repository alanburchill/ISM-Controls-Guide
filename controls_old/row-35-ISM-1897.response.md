## Summary

Remote Credential Guard is enabled to protect credentials across Remote Desktop sessions.[^1] Enable Remote Credential Guard on devices using Microsoft Intune via a custom configuration or a Settings Catalog policy that configures credential delegation, per Microsoft Learn guidance.[^2]

## Design Decision

> [!NOTE] Enable Remote Credential Guard using an Intune custom configuration policy to protect credentials during Remote Desktop sessions.

## Prerequisites

* **Licensing:** Windows license entitlements for Remote Credential Guard are provided by Windows editions: Windows Pro/Pro Education/SE, Windows Enterprise (E3/E5), and Windows Education (A3/A5). [^1]
* **Permissions/Roles:** Not provided in source documentation. [^1]
* **Dependencies:** Intune/MDM must manage devices; devices must be enrolled in Intune and grouped for policy assignment; enable Remote Credential Guard via Settings Catalog policy or a custom policy using the Policy CSP; Remote Credential Guard prerequisites require: remote host must allow Remote Desktop connections and delegation of nonexportable credentials to the client; the client device must run the Remote Desktop Windows app and use Kerberos authentication (no NTLM fallback); RDG can be used only with devices joined to Active Directory (not Entra ID joined); RDG works only over the RDP protocol; licensing entitlements must exist for the cited Windows editions. [^1]

## Implementation Steps

### Enable Remote Credential Guard via Intune Settings Catalog

1. Create an Intune Settings Catalog policy.  
2. In the policy, configure the following two settings:

   2.1 Category: Administrative Templates > System > Credentials Delegation  
       Setting name: Remote host allows delegation of nonexportable credentials  
       OMA-URI: ./Device/Vendor/MSFT/Policy/Config/CredentialsDelegation/RemoteHostAllowsDelegationOfNonExportableCredentials  
       Data type: string  
       Value: `<enabled/>`  
       Note: This enables delegation of nonexportable credentials on remote hosts.[^1]

   2.2 Category: Administrative Templates > System > Credentials Delegation  
       Setting name: Restrict delegation of credentials to remote servers  
       OMA-URI: ./Device/Vendor/MSFT/Policy/Config/ADMX_CredSsp/RestrictedRemoteAdministration  
       Data type: string  
       Value: `<enabled/><data id="RestrictedRemoteAdministrationDrop" value="2"/>`  
       Note: In the Intune UI, select one of the following options in the dropdown:  
       - Restrict Credential Delegation  
       - Require Remote Credential Guard  
       Possible values for RestrictedRemoteAdministrationDrop are: 0 Disabled, 1 Require Restricted Admin, 2 Require Remote Credential Guard, 3 Restrict credential delegation. This policy allows enforcing Remote Credential Guard on the client remote sessions.[^1]

3. Assign the policy to a group that contains the devices or users you want to configure.[^1]

4. After the policy is applied, restart the device to apply Credential Guard-related settings.[^2]
