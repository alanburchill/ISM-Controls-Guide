## Summary

Onboard all endpoints to Microsoft Defender for Endpoint.[^2] Then access the Defender security portal and view vulnerability data in Exposure management > Vulnerabilities to identify and manage weaknesses across devices.[^4] Defender Vulnerability Management provides continuous visibility, assessment, and remediation workflows for onboarded devices.[^3]

## Design Decision

> [!NOTE] Onboard devices to Microsoft Defender for Endpoint and then use the Microsoft Defender security portal report under Exposure management > Vulnerabilities.

## Prerequisites

* **Licensing:** Licensing must include Microsoft Defender Vulnerability Management (standalone) or Defender for Endpoint Plan 2 or E5. [^1]
* **Permissions/Roles:** Access to the Microsoft Defender portal requires the Security Reader role or higher. [^1]
* **Dependencies:** Devices must be onboarded to Microsoft Defender for Endpoint. Defender Vulnerability Management must be onboarded per Defender portal guidance. [^2][^4]

## Implementation Steps

### Onboard devices to Microsoft Defender for Endpoint and access Vulnerabilities report

1. Onboard devices to Defender for Endpoint using the Defender portal onboarding workflow.
   - Go to the Onboarding section in the Microsoft Defender portal.
   - Choose the device OS.
   - Select a Deployment method.
   - Follow the instructions to onboard the devices.
   - [^4]

2. Alternatively, onboard devices via Intune.
   - Create a Windows Configuration Profile with:
     - Platform: Windows 10 and later
     - Profile type: Templates > Microsoft Defender for Endpoint
   - Enable telemetry by setting Expedite to Enable.
   - Assign the profile to a group containing all applicable Windows devices.  
   - [^2]

3. Onboard devices to Defender Vulnerability Management (DVM).
   - In the Defender portal onboarding flow, choose Defender Vulnerability Management onboarding.
   - Select the OS and Deployment Method, then follow the on-screen steps to onboard.  
   - [^4]

4. Access the Vulnerability report in the Defender portal.
   - In the Microsoft Defender portal, navigate to Exposure management > Vulnerabilities to view the vulnerabilities data and remediation options.  
   - For detailed software vulnerability inventories, navigate to Vulnerability Management > Inventories in the portal.  
   - [^1]
